## 読み方

| 列 | 説明 |
|---|---|
| キーワード | 読者がGoogle/note内検索で打ち込む言葉（2〜4語） |
| 検索意図 | そのキーワードを検索する人が本当に知りたいこと |
| 優先度 | 高（今すぐ作る）/ 中（次のフェーズ）/ 低（様子見） |
| 無料記事タイトル | 作成済みの場合は記事タイトルを記載 |
| 状態 | 待機中 / 作成済み / 公開済み / 増築中 |
