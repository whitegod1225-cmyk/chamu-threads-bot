# バズ投稿の型｜ファッション・暮らし系

> **用途**: ファッション／インテリア／雑貨／育児グッズ／食品系アカウントで、コメント欄の商品紹介・アフィリエイトに着地させる投稿を作るときに参照する。
> **読む順番**: kapi-writing-rules.md → kapi-first-lines-image.md → このファイル（kapi-post-patterns-image.md）。
> **姉妹ファイル**: kapi-post-patterns.md（コメント誘導型の汎用パターン集）。役割が違うので混ぜない。

---

## 収録している型（一覧）

| ファミリー | 型 | 一言でいうと | 得意な訴求 |
|---|---|---|---|
| **A. リアルストーリー型** | 1. 基本形 | 店で見かけた人の話→マイナス予感で切る | 単品商品・日常使い |
| | 2. 二段引き | コメント欄でもう一度引く | 滞在時間を伸ばしたい時 |
| | 3. 連鎖紹介 | 1シーンから複数商品 | 収益機会を増やしたい時 |
| **B. 買いません連呼型** | 4. 基本形 | 定番店を連呼で否定→答えを伏せる | セール・お得訴求 |
| | 5. 連鎖セール | コメント欄で他ブランドも畳みかける | セール期間中 |
| **C. ごめん型** | 6. 基本形 | 「ごめん、」1〜2行だけで切る最小形 | 画で見せる単品商品 |
| **D. 固有名詞直球型** | 7. 基本形 | ブランド名＋感嘆だけ。**伸び率は低い** | 新作・コラボの速報 |
| **E. 後悔・警告型** | 8. 基本形 | 「買わないほうがいい」→良すぎるに反転 | 自分が心から推せる商品 |

**共通する大原則**：本文の仕事は「情報を伝えること」ではなく**タップさせることだけ**。商品名・値段・リンクは全部コメント欄に回す。

**主軸はA・B・C・E**（Eは自分の体験がある商品で強い）。Dは新作速報の埋め草として使い、メインには据えない（→ ファミリーDの「位置づけ」参照）。

# 投稿作成の手順（入口）

> **画像勝負タイプの投稿は、必ずここから始める。** コンテキストに入れる3ファイルだけで完結する。
> 読む順番：`kapi-writing-rules.md`（文字数・禁止・パクリ回避）→ `kapi-first-lines-image.md`（1行目の索引）→ このファイル（型の本体）。

入力は2種類ある。どちらかを判断してフローを選ぶ。

- **A. 商品画像が貼られた**（楽天などの商品画像＋商品タイトルが分かる画像）→ **基本フロー**
- **B. 既にバズっている投稿が貼られた**（スレッズ/Xのスクショや本文）→ **例外フロー**

---

## 基本フロー（商品画像が貼られたら）

### STEP 0｜スクショから読み取る
楽天などの商品画像・タイトルから次を拾う。分からない項目は空欄でよい。
- 商品ジャンル（服／靴／バッグ／雑貨／インテリア／育児グッズ／食品／コスメ 等）
- ブランド名・商品名（有名ブランドか、無名か）
- 値段・セール/クーポン表示の有無
- 画像の枚数と中身（色柄バリエが並ぶ／形が特徴的／人が着用／単品）

### STEP 1｜「本文」だけを5案作る
**いきなりコメント欄まで作らない。まず本文を5案出す。**
- 5案は**互いに異なる型・異なるフック**にする（同じフックを繰り返さない）
- **必ず1案は「リアルストーリー型」を入れる**（実測で最も伸びる。毎回入れる＝絶対ルール）
- 残り4案は、下の判定基準でこの商品に合う型から選ぶ
- 文字数は `kapi-writing-rules.md` §2 の**型別ルール**に従う
- **本文に商品名・値段・リンクを書かない**（画像が説明する）。1行目は「、、、」「...」で切る

#### この商品にどの型が向くかの判定基準
| 型 | ◎ 向いている | △ 向かない |
|---|---|---|
| **リアルストーリー型（必ず入れる）** | 服・育児グッズなど「人が使う場面」が浮かぶ | ― （場面はこちらで補完して必ず1案作る） |
| **買いません連呼型** | セール/クーポン表示、定番店で買えるジャンル | 一点物・無名ブランドで比較が効かない |
| **ごめん型** | 色柄バリエが多い／形が特徴的で画が強い | 見た目が地味・画像1枚 |
| **固有名詞直球型** | 誰でも知る有名ブランドの新作・コラボ・新色 | 無名ブランド、出尽くした定番（伸びない） |
| **後悔・警告型** | 自分が実際に使って心から良いと思える商品（定番・バズ品） | 使ったことがない／推せない商品 |

### STEP 2｜5案を提示して選んでもらう
番号つきで5案を並べ、各案に〔型名〕を添えて、こう聞く：

```
この商品なら、こんな本文が作れます👇

1.〔本文〕（リアルストーリー型）
2.〔本文〕（〇〇型）
3.〔本文〕（〇〇型）
4.〔本文〕（〇〇型）
5.〔本文〕（〇〇型）

この5つの中で、あなたが一番タップして続きを読みたくなった投稿はどれですか？
その投稿の続き（コメント欄）を作ります。
```

### STEP 3｜選ばれた1案をコメント欄まで完成させる
1. 選ばれた本文の型のファミリーを開き、「ブロック構造」に沿って**コメント欄**を作る
2. **店名・シーン・登場人物はこちらで自然に補完**してよい（スクショに無くてよい）
3. `kapi-writing-rules.md` の「コメント欄の書き方（**反転から入る**）」を守る
4. 該当ファミリーの**チェックリストと禁止チェック**を全項目通す

#### 完成版の出力フォーマット（固定）
```
【本文】
〔選ばれた1行目。商品名・値段・リンクは書かない。「、、、」「...」で切る〕

【コメント1】
〔反転：褒め／驚き／後悔／解消。マイナスは言わない〕
〔補強：使用感・本人談・数字・こだわり〕

【コメント2】
〔値段・クーポン・サイズ感を一言／質問・呼びかけ〕
⇛ 商品リンク（pr）  ← 実URLはユーザーが差し込む前提で「⇛ 商品リンク（pr）」と置く
```

## 例外フロー（既にバズっている投稿を貼られたら）

ユーザーがスレッズ/Xで**既にバズっている他人の投稿**を貼って「これで作って」「参考に」などと言った場合。

1. 貼られた投稿の**商品・テーマ・使われている型**を読み取る
2. **元の投稿とは別の型で作り直す**（同じ型をそのままなぞらない）
   - 例：貼られたのが「ごめん型」なら、リアルストーリー型・買いません連呼型・後悔警告型などで作る
   - **理由**：他人の投稿の丸パクリを避けるため。型を変えることで自分の投稿になる
3. STEP 1〜3 と同じく**本文を5案**出す。**このときも必ず1案はリアルストーリー型を入れる**
4. `kapi-writing-rules.md` の**§7 パクリ回避を必ず適用**する（言葉ではなく「読者を動かした仕組み」を真似る／構造も表現も機能で捉えて言い換える）

> 商品画像が無くテキストだけ貼られた場合も同様。読み取れる商品・テーマから5案を作る。

# ファミリーA｜リアルストーリー型

## リアルストーリー型とは

「実際にあった出来事」として語られる**目撃談・遭遇談**から入り、コメント欄で商品紹介につなげる構造。現在のThreadsで最も伸びている形。

```
【本文】（80〜200文字）
実店舗のシーン → 見かけた人・アイテム → ★マイナスを予感させるフレーズで切る

【コメント欄1】
反転（実は絶賛・驚き・後悔）→ 理由 / 使用感 / 聞いた話

【コメント欄2以降】
商品の詳細・値段・お得情報 → 商品リンク（pr / PR表記）
```

### 3つの必須要素

| 要素 | 内容 | 役割 |
|---|---|---|
| **① 大手企業名** | コストコ / 無印 / セリア / イオン / ユニクロ / アウトレット など | アルゴリズム拡散＋実話っぽさ |
| **② 他人の目撃談** | 自分の話ではなく「見かけた人」の話にする | 押し売り感の除去＋覗き見の興味 |
| **③ ★引きフレーズ** | 本文の最後。マイナスを予感させて切る | **この型の心臓。タップの燃料** |

---

## なぜこの型が伸びるのか（リアルストーリー型）

**① タイムラインではコメント欄が見えない**
Threadsのタイムラインに出るのは本文だけで、続き（コメント欄）は隠れている。つまり本文の仕事は「情報を伝えること」ではなく、**タップさせることだけ**。タップされた瞬間に滞在時間が伸び、アルゴリズムが一気に配信を広げる。逆にタップされなければ何も起きない。

**② 人は"悪い話"を確認せずにいられない**
褒め話はスクロールで飛ばせる。だが悪口・不満・失礼な話は「え、何を言うの？」で指が止まる。だから本文は「この後マイナスなことを言うぞ」と思わせる位置で切る。**ネガティブの予感がタップの燃料**になる。

**③ 大手企業名がアルゴリズムに拾われる**
コストコ・無印・セリア・イオンなど検索需要の大きい固有名詞を入れると、そのワード目当ての層にも配信が伸びる。実店舗名は「実話っぽさ」の担保にもなるので一石二鳥。

**④ 期待を裏切ってプラスに反転させる**
コメント欄では**マイナスなことを一切言わない**。全部プラスに反転させる。読者は「悪口かと思ったら褒めてた」という安心と好感を得て、その気分のまま商品リンクを見る。悪口で終わると嫌われて終わるが、反転させると好かれる。**ここを絶対に間違えない。**

## ブロック構成（リアルストーリー型）

この型は専用のブロック記号で扱う（他ファイルのA〜Fとは別体系）。

| # | ブロック | 役割 | 置く場所 |
|---|---|---|---|
| **S** | シーン | いつ・どこで・誰を見たか。実在の店舗名を入れる | 本文 |
| **T** | 対象 | 見たアイテム・服装・持ち物への言及 | 本文 |
| **★** | 引き | マイナスを予感させて本文を切る | 本文の最後 |
| **R** | 反転 | 実は褒め・驚き・後悔だったと明かす | コメント1の1行目 |
| **D** | 補強 | 理由・使用感・本人から聞いた話・自分の失敗談 | コメント1 |
| **F** | 締め/CTA | 値段・お得情報 → 商品リンク（pr） | コメント2以降 |

**S → T → ★ ／ R → D → F**。この順番は崩さない。

---

## ★引きフレーズ集（リアルストーリー型）

**この型の成否は9割ここで決まる。** 迷ったらこの中から選ぶ。

| タイプ | フレーズ例 | 読者の予感 |
|---|---|---|
| **謝罪型** | 「ごめん、」「..ほんとすみません、」「ごめんなさい、〇〇さん。」 | 今から失礼なこと言うんだな |
| **逆接型** | 「かわいいのは分かるんだけどさぁ、」「服も可愛かったんだけど、」 | 褒めた後に落とすんだな |
| **判定保留型** | 「こういうママって...」「こういう場では、」「この格好はさすがに」 | 何か言いたいことがあるんだな |
| **発言権主張型** | 「〇〇好きの私から言わせると...」「一応その道の人間として言うけど、」 | 専門家目線でダメ出しするんだな |
| **過去回想型** | 「学生の時から思ってたんだけど..」「前から言おうと思ってたんだけど、」 | ずっと溜めてた不満が出るんだな |
| **自己否定投影型** | 「私なら選ばなかったなって思ってしまった...」「自分だったら無理かも、」 | 否定的な評価をしてるんだな |
| **二度見型** | 「思わず二度見。だって、どう見ても、、」 | ありえないものを見たんだな |

### 引きの作り方3原則
1. **文を言い切らない。** 「、」「...」「..」で切る。句点で終わらせると読者は完結したと感じてタップしない。
2. **ネガティブの"匂い"だけ出す。** 実際に悪口を書かない。書くと反転が効かなくなるし、コメント欄まで悪口だと嫌われる。
3. **主語を相手にする。** 「私が」ではなく「あの人が」。他人への評価に見せると覗き見の興味が乗る。

## パターン一覧（リアルストーリー型）

**実例の文言はそのまま使わない。構造とブロックの組み立て方を理解して、自分のネタで作り直す。**

---

### 1. リアルストーリー型（基本形）

> 実店舗で見かけた人の服装・持ち物を語り、本文の最後をマイナス予感フレーズで切る。コメント欄で全部プラスに反転させて商品リンクへ流す。この型のすべての基礎。

**本文の例（バリエーションA：判定保留型）**
```
この前コストコで、
ふんわりスカート履いてる可愛いママがいて...👀

服も可愛かったんだけど、
こういうママって...
```

**コメント欄に置く内容**
足元まで褒める（実は絶賛だった）＋ ブランド名と可愛かった理由 ＋「私も真似したくなった」＋ 商品リンク（pr）

---

**本文の例（バリエーションB：逆接型）**
```
昼からアウトレットの室内遊び場に。
ママさんが2人もこんな感じのベスト着てらして..
かわいいのは分かるんだけどさぁ、
```

**コメント欄に置く内容**
「〜だと思ってたから、こんなに可愛いんだって驚きの方が大きかった」＝否定ではなく驚き ＋「もしかして流行ってるんかな」＋ 半額クーポン情報 ＋ 商品リンク（pr）

---

**本文の例（バリエーションC：謝罪型・服装ダメ出し風）**
```
いっっつもスウェットのママ友が近所のイオンで買い物してて。
どうやら仕事帰りらしいんだけど..
この格好はさすがにごめん、
```

**コメント欄に置く内容**
「きれいなお姉さん度高すぎて..ギャップにびっくり」＝ごめん＝褒めちゃってごめん ＋ 本人から聞いた背景（仕事がかちっとしてる反動でラフにしてる）＋「お揃いにしたくなった」＋ 使えるシーン（参観日・懇談）＋ 商品リンク（pr）

---

**本文の例（バリエーションD：謝罪型・マナー指摘風）**
```
イオンのフードコートで小さい子にお薬あげてるママさんがいらして。
..ほんとすみません、こういう場では、
```

**コメント欄に置く内容**
「じろじろ見てしまいました」＝謝ってたのは自分の行動 ＋ 自分の失敗談（うまく飲ませられなくて諦めてた）＋ 商品の利点（1回分だけ持ち運べる）＋ 商品リンク（pr）

---

**本文の例（バリエーションE：過去回想型）**
```
久々にコストコのフードコート行ったら、高校の時の友達にばったり遭遇。
えっとさ、学生の時から思ってたんだけど..
```

**コメント欄に置く内容**
「ラフな服をおしゃれに着こなすほんと上手」＝ずっと思ってたのは称賛 ＋ 本人に聞いた着こなしのコツ ＋ 値段の驚き（クーポンで半額）＋ 商品リンク（pr）

---

**本文の例（バリエーションF：自己否定投影型）**
```
無印で見かけた妊婦さん。
オールインワンって......
ごめん、妊娠中の私なら選ばなかったなって思ってしまった...
```

**コメント欄に置く内容**
「妊娠中はワンピースばっかりだったけど産後ほんっとに着なくなって」＝選ばなかった過去の自分が間違いだった、という後悔 ＋「今思えば妊娠中からこういう服にしておけばよかった」＝実質の最大級の推薦 ＋ 商品リンク（pr）

---

**本文の例（バリエーションG：ブランドに謝る型）**
```
ごめんなさい、無印さん。
友達がバッグからこれ出してきて思わず二度見。
だって、どう見ても、、
```

**コメント欄に置く内容**
「無印っぽい透明感なのに、耐熱ガラスでホットもアイスもいけるのずるい」＝無印そっくりで無印より高機能 ＋ 使用シーンの絵（アイスコーヒー入れたらおしゃれマイボトル）＋「〇〇好きに刺さりそう、置いときます」＋ 商品リンク（PR）

> **補足**：この型だけは目撃対象が「人」ではなく「ブランド」。定番ブランドに謝る形にすると、そのブランドの検索層をまるごと拾える。ファンを敵に回さないよう、コメント欄では必ずそのブランドを立てる。

---

**コメント欄の構成（例｜本文の切れ目の続きから）**
本文は「、」「...」で途中で切れている。その続きとして1本の文章で書く。
① 引きを反転して回収（褒め／驚き／後悔のどれか）→ ② 理由・使用感・本人から聞いた話 → ③ 自分の気持ち（真似したい／お揃いにしたい／助かる）→ ④ 商品〇〇（pr）→ ⑤〈お得系のみ〉値段・クーポン・セールを一言

**コメント欄の実例**（〇〇＝ブランド名・商品名・リンク）
```
（服・褒め反転）
足元までちゃんとオシャレなんだよね🥺
歩きやすそうなだけじゃなくて、
〇〇のレオパードがいい感じに効いてて
めっちゃ可愛かったの🤍
私も真似したくなった🥺
⇛ 〇〇（pr）
```
```
（後悔反転）
妊娠中はワンピースばっかり着てたんだけど、産後ほんっとに着なくなって😂
抱っこに授乳に、動くから結局パンツタイプがいいんよね。
今思えば、妊娠中からこういう服にしておけばよかったな〜！！
⇛ 〇〇（pr）
```
```
（値段で締める）
クーポンで半額？
２着でこれって..〇〇もびっくりじゃん。
⇛ 〇〇（pr）
```

**ブロック構造**
- S：実店舗名＋シチュエーション（「この前コストコで、」「イオンのフードコートで、」）
- T：見かけた人とアイテム（「ふんわりスカート履いてる可愛いママ」「こんな感じのベスト」）
- ★：マイナス予感フレーズで言い切らずに切る（「こういうママって...」「さすがにごめん、」）
- R：コメント1行目で反転。褒め／驚き／後悔のどれかに着地
- D：理由・使用感・本人談・自分の失敗談で厚みを出す
- F：値段・お得情報を添えて商品リンク（pr）

**この型が効く仕組み**
タイムラインでは本文しか表示されないため、本文の唯一の仕事はタップを取ること。悪口の予感は「確認せずにいられない」心理を強制的に起動させるので、内容の魅力に頼らずタップが取れる。さらに実店舗名が実話性とアルゴリズム露出を同時に稼ぐ。タップ後は期待を裏切ってプラスに反転させるので、読者は不快になるどころか好感を持ったまま商品情報にたどり着く。**「ネガティブで引く／ポジティブで返す」の落差そのものが装置。**

**自分のネタで作るには**
売りたい商品から逆算して、その商品が自然に登場するシーン（店・場所・人）を1つ決める。自分ではなく「そこで見かけた人」が使っている設定にする。本文は3〜4行で、店名 → 見た人とアイテム → 引きフレーズ、で切る。**商品名・値段・リンクは本文に一切書かない。** 全部コメント欄に回す。コメント欄では絶対にマイナスを書かず、引きを褒め・驚き・後悔のいずれかに反転させてから商品へつなぐ。

---

### 2. 二段引き型（コメント欄でもう一度引く）

> 基本形の応用。コメント1でいったん反転させて安心させた後、**コメント1の最後をもう一度マイナス予感で切る**。2回タップを取れるので滞在時間がさらに伸びる。

**本文の例**
```
セリアのレジにこれ持って並んでる人いたけどさ、
サンリオ好きの私から言わせると...
```

**コメント欄1（反転 → 再び引く）**
```
この可愛さはずば抜けてる。
しかも、その人この中の2つ持っててどっちも可愛かった。
ちょっと残念だったのは...
```

**コメント欄2（2回目の反転 → リンク）**
```
〇〇はもうないみたい。でも、他の狙いはあったから嬉しすぎ！
PR 〇〇
```

**ブロック構造**
- S/T/★：基本形と同じ（本文で1回目の引き）
- R：コメント1で絶賛に反転
- ★2：コメント1の最後で「ちょっと残念だったのは...」と再び引く
- R2/F：コメント2で「残念＝売り切れ」程度の軽い事実に着地させ、すぐプラスで打ち消してリンク

**この型が効く仕組み**
1回目の反転で「この人は悪口を言わない人だ」と分かった直後に、また不穏な引きが来る。安心した直後の再引きは警戒されにくく、素直にもう1タップされる。2回目の「残念」は**在庫切れ・別売り・色欠け程度の無害な事実**に留めるのがコツ。商品自体の欠点にすると購買意欲が落ちる。

**自分のネタで作るには**
2段目の引きは「惜しい話」を用意する。売り切れていた色、別売りのオプション、もう1つ買えばよかった、など。**商品の性能をけなす方向には絶対に振らない。** 2段目の反転は短く1〜2行で切り上げて、すぐリンクへ流す。

---

### 3. 連鎖紹介型（1シーンから複数商品へ）

> ひとつの目撃シーンから、コメント欄を伸ばして2〜3個の商品を紹介する。1投稿あたりの収益機会を増やす形。

**本文の例**
```
イオンのフードコートで小さい子にお薬あげてるママさんがいらして。
..ほんとすみません、こういう場では、
```

**コメント欄の流れ**
```
【コメント1｜反転＋自分の失敗談】
上手く飲ませることできないと思って、、
自分は諦めてたからこんなのあるの？！って
じろじろ見てしまいました😭
1回分だけ持ち運べるの助かるなぁ。

【コメント2｜商品①＋率直な迷い】
3つでこれは嬉しいかも。
ただ専用ポーチが別売りであるけど、こっちはコスパ的にどうなんだろ🤔
⇛ 〇〇（pr）

【コメント3｜"そういえば"で商品②へ】
そういえば、これはご飯の後だったけど
食べてる時〇〇みたいなのしてて。
違うかもだけどここのやつかも..
てか他のデザインもめっっちゃかわいいんだが。
⇛ 〇〇（pr）
```

**別の流れ（後日談でつなぐ）**
```
【コメント3｜商品①＋値段の驚き】
クーポンで半額？２着でこれって..〇〇もびっくりじゃん。
⇛ 〇〇（pr）

【コメント4｜"あの後"で商品②へ】
あの後、おしゃれな服教えてくれてありがとーってラインしたら
「これも同じような感じだから、色とかで選んでもいいと思うー👍」って！
そしてまたしても半額。。
⇛ 〇〇（pr）
```

**ブロック構造**
- S/T/★/R/D：基本形と同じ
- F1：商品①のリンク
- 接続：「そういえば、」「あの後、」「もうひとつ言うと、」で自然に次の商品へ
- F2：商品②のリンク

**この型が効く仕組み**
同じシーンの中の別要素（子どもが着けていたもの、一緒に持っていたバッグ）や、その後のやりとり（お礼のLINE）を使うと、商品を追加しても話が途切れない。**「紹介」ではなく「話の続き」の顔で出せる**ので、宣伝感が増えないまま接点だけが増える。

**自分のネタで作るには**
商品を2〜3個まとめて選ぶときは、**同じシーンに同時に存在しうるもの**を選ぶ。服なら「服＋バッグ＋アクセ」、育児なら「投薬ボトル＋エプロン」。無関係な商品を並べると急に広告になる。接続は必ず「そういえば」「あの後」など雑談の接続詞で始める。3個までが上限、それ以上は離脱する。

## 商品から投稿を作る手順（リアルストーリー型）

**ユーザーから商品が投げられたら、この順で組み立てる。**

### STEP 1｜商品からシーンを逆算する
「この商品を持っている人を、どこで見かけたら自然か」を決める。

| 商品ジャンル | 相性のいい場所 |
|---|---|
| 服・アウター・セットアップ | コストコ / イオン / アウトレット / スーパー / 保育園のお迎え / 参観日 |
| 靴・バッグ・アクセ | 上記に加えて フードコート / 室内遊び場 |
| キッチン・水筒・保存容器 | 職場 / カフェ / 友達の家 / ジム |
| 収納・インテリア雑貨 | 無印 / ニトリ / セリア / ダイソー / 友達の家 |
| 育児グッズ | イオンのフードコート / 児童館 / 小児科 / 支援センター |
| 文具・サンリオ系雑貨 | セリア / ロフト / 学校 |

**大手企業名は必ず1つ入れる。** 迷ったらコストコ・無印・イオン・セリア。

### STEP 2｜目撃する人物を決める
自分ではなく他人にする。
- 知らないママ／妊婦さん／店で並んでた人（＝距離が遠い。批評しやすい）
- ママ友／高校の友達／同僚（＝後で会話を引き出せる。連鎖紹介型向き）

### STEP 3｜★引きフレーズを選ぶ
上の「引きフレーズ集」から商品に合うものを選ぶ。
- 服装を褒めたい → 逆接型・判定保留型
- 自分が知らなかった便利グッズ → 謝罪型（じろじろ見てすみません）
- 定番ブランドの類似・上位互換 → ブランドに謝る型
- 「買っておけばよかった」系 → 自己否定投影型

### STEP 4｜反転の中身を決める
コメント1で言うのは次のどれか1つ。**マイナスは書かない。**
- **褒め**：足元まで／色が／着こなしが素敵だった
- **驚き**：そんな使い方があるんだ／こんなに可愛いんだ
- **後悔**：自分は諦めてた／選ばなかった過去の自分が間違いだった
- **羨望**：真似したくなった／お揃いにしたくなった

### STEP 5｜商品情報を最後に置く
値段・クーポン・セール・サイズ感を一言 → 商品リンク（pr / PR 表記は必須）。
**本文には商品名も値段もリンクも書かない。**

# ファミリーB｜買いません連呼型

## 買いません連呼型とは

誰もが知る定番の店・ブランドを並べて「買いません」と2〜3回連呼し、**答え（じゃあどこで買うのか）を言わずに本文を切る**。コメント欄で答えを明かして商品リンクへ流す。セール訴求・お得訴求で最も強い型。

```
【本文】（60〜150文字）
宣言 → 「〇〇では買いません」を2〜3回連呼 → ★答えを伏せて切る

【コメント欄1】
答え＝セール情報 / 本命ブランド / 理由 → 商品リンク（pr）

【コメント欄2以降】
他ブランドのセールを畳みかける（任意）
```

> **姉妹ファイルとの関係**：kapi-post-patterns.md「1. 断言連呼型」のバリエーションDと同じ骨格。こちらはセール・お得訴求に特化させた発展形として扱う。

---

## なぜこの型が伸びるのか（買いません連呼型）

**① 定番を否定するギャップで足が止まる**
ユニクロ・イオン・西松屋・シャトレーゼなど、誰もが使っている店を名指しで否定する。読者は「え、なんで？」「じゃあどこで買うの？」と反射的に理由を探す。**否定は肯定より止まる。**

**② 連呼のリズムが視覚的に目立つ**
同じ構文が縦に3行並ぶと、文字を読む前に「何か強い主張がある」と目に飛び込む。タイムラインの中で塊として認識される。

**③ 答えを伏せているのでタップするしかない**
本文で答えを言わないから、続きはコメント欄をタップするしかない。**この型は「答えを隠す」ことが全て。**

**④ 大手企業名を3つ以上入れられる**
1投稿に定番ブランド名が3つ以上入るので、それぞれの検索・興味層に配信が乗る。リアルストーリー型より固有名詞の密度が高い。

---

## ★答えの伏せ方（本文の最後）

| タイプ | フレーズ例 | 備考 |
|---|---|---|
| **理由フリ型** | 「だって、」「なぜなら、、」「なぜなら......」 | 最も強い。答えを完全に伏せる |
| **犯人名指し＋再フリ型** | 「〇〇のせいです。だって、」 | ブランド名は出すが理由は伏せる |
| **理由言い切り型** | 「自己負担2000円で1年もつからです。」 | 理由自体が謎なときだけ成立する上級形 |

### 絶対ルール：本命ブランド名で終わらない

「だって、〇〇が」のように**本命ブランド名を出したところで切ると伸びが落ちる**。読者に答えが割れてしまい、タップする必要が消えるため。実測でもこの終わり方の投稿だけ表示数が一桁落ちている。

ブランド名を出すなら、その後に必ず「だって、」「なぜなら、、」を重ねて理由まで伏せる（＝犯人名指し＋再フリ型）。**迷ったらブランド名は本文に出さず、コメント欄まで引っ張る。**

```
✕ だって、LOWRYS FARMが          ← 答えが割れる
◯ FREAK'S STOREのせいです。だって、  ← 名前は出すが理由は伏せる
◎ だって、                        ← 完全に伏せる（最強）
```

## ブロック構成（買いません連呼型）

| # | ブロック | 役割 | 置く場所 |
|---|---|---|---|
| **N** | 宣言 | 「【ご報告】」「はい、」などの前置きで身構えさせる | 本文 |
| **X** | 否定連呼 | 「〇〇で買いません」を2〜3回 | 本文 |
| **★** | 伏せ | 答えを言わずに切る | 本文の最後 |
| **R** | 答え | セール情報・本命ブランド・理由 | コメント1の1行目 |
| **D** | 補強 | 割引率・対象店舗数・こだわり・使い方 | コメント1 |
| **F** | 締め/CTA | 商品リンク（pr）／他ブランドへの連鎖 | コメント1以降 |

**N → X → ★ ／ R → D → F**。

### 連呼の2方向

| 方向 | 固定するもの | 変えるもの | 例 |
|---|---|---|---|
| **店ずらし**（基本） | 商品 | 店・ブランド | 夏の服は、ユニクロで／しまむらで／イオンでも買いません |
| **商品ずらし**（応用） | 店 | 商品 | トイレットペーパー、イオンで／ティッシュ、イオンで／キッチンペーパーも、イオンで買いません |

商品ずらしは「その店の何もかもを買わない」という強い宣言になるので、ふるさと納税・定期便・まとめ買いなど**買い方そのものを変える提案**と相性がいい。

### 4. 買いません連呼型（基本形）

> 定番の店を2〜3回否定して並べ、答えを伏せて切る。コメント欄で答えを明かして商品リンクへ流す。

**本文の例（バリエーションA：理由フリ型／本命を完全に隠す）**
```
バームクーヘンは、ねんりん家で買いません。
クラブハリエでも買いません。
治一郎でも買いません。
だって、
```

**コメント欄に置く内容**
本命ブランドが選ばれる理由をひとこと（安心安全のメーカーだから）＋ 理由を箇条書きで3〜4つ ＋ 歴史・こだわりで権威づけ ＋ 使うシーン（お中元・帰省土産）＋ 商品リンク（pr）

---

**本文の例（バリエーションB：ご報告＋なぜなら型）**
```
【ご報告】
シュークリームは...
シャトレーゼで買いません。
ビアードパパで買いません。
なぜなら......
```

**コメント欄に置く内容**
その商品ならではの体験（冷凍のまま／少し解凍で2度楽しめる）＋ 食感の描写（皮はパリッパリ、生地はザックザク）＋「〜したい人はチェックしてみて👇」＋【PR】リンク

> 連呼は**2回でも成立する**。3回にこだわらない。

---

**本文の例（バリエーションC：ジャンル宣言型）**
```
はい、韓国コスメは
LOFTで、買いません。
PLAZAでも、買いません。
Qoo10でも、買いません。

なぜなら、、
```

**コメント欄に置く内容**
セール名＋割引率を1行目で即答 ＋ 対象ブランドを『』で羅列 ＋ 対象店舗数などの数字 ＋ セット商品のお得さ ＋ 商品リンク（pr）

---

**本文の例（バリエーションD：犯人名指し＋再フリ型）**
```
【ご報告】

夏の服は、ユニクロで買いません。
夏の服は、しまむらで買いません。
夏の服は、イオンでも買いません。

FREAK'S STOREのせいです。だって、
```

**コメント欄に置く内容**
セール開始の驚き ＋ 時期へのツッコミ（夏本番これからよ？！）＋ 割引率の数字 ＋ 商品リンク（pr）→ そのまま連鎖セール型（型5）へつなげられる

---

**本文の例（バリエーションE：商品ずらし＋理由言い切り型）**
```
【ご報告】
トイレットペーパー、イオンで買いません。
ティッシュペーパー、イオンで買いません。
キッチンペーパーも、イオンで買いません。
自己負担2000円で1年もつからです。
```

**コメント欄に置く内容**
仕組みの説明（玄関まで届く／自己負担2,000円で生活必需品）＋ 浮いたお金の使い道（ディズニー貯金してミラコスタ泊まります）＋ ランキング情報 ＋ 商品リンク（pr）

> 理由を言い切っているが、「自己負担2000円で1年もつ」という文自体が謎なので引きが成立している。真似するのは**理由が謎めいている時だけ**。普通の理由を言い切ると一気に伸びなくなる。

---

**コメント欄の構成（例｜本文の切れ目の続きから）**
本文は「だって、」「なぜなら、、」で切れている。その答えとして続ける。
① **1行目で答えを即答**（セール名／割引率／本命ブランドと理由）→ ② 数字・箇条書き・体験で補強 → ③ 使うシーン・おすすめの相手 → ④ 商品〇〇（pr）

**コメント欄の実例**（〇〇＝ブランド名・商品名・リンク）
```
（セール即答）
〇〇で20%OFFだからです...！📣

『〇〇』『〇〇』『〇〇』『〇〇』も...！！
対象ショップ94店舗もあるっ！！！
セット商品がかなりお得になってた！！
⇛ 〇〇（pr）
```
```
（こだわり権威）
〇〇が『安心安全』のメーカーだから🙌
国産バター100%使用や、ショートニング・乳化剤も使ってないんだもん🥺

〇〇は、
・素材本来の味を大切にしてる
・不要な食品添加物を使わないお菓子作り
・添加物を使わない代わりに職人の技術で品質維持

100年以上歴史がある会社なのって本当に素晴らしいよね！
⇛ 〇〇（pr）
```

**ブロック構造**
- N：【ご報告】／はい、／〇〇は... で前置きを作り、身構えさせる
- X：「〇〇で買いません」を2〜3回。最後の1回は「〜でも買いません」と助詞を変えて畳みかける
- ★：「だって、」「なぜなら、、」で切る。**答えは書かない**
- R：コメント1行目で答えを即答（引っ張り直さない）
- D：割引率・店舗数・こだわり・使い方で厚みを出す
- F：商品リンク（pr）

**この型が効く仕組み**
定番の否定＝常識破壊で足が止まり、連呼のリズムで塊として目立ち、答えを伏せることでタップが確定する。3つの装置が同時に効く。さらに本文に定番ブランド名が3つ以上入るので、固有名詞由来の配信も伸びる。**タップを取る力が構造そのものに埋まっているので、ネタの新しさに依存しない。**

**自分のネタで作るには**
売りたい商品のジャンルを決めたら、**そのジャンルで誰もが真っ先に思い浮かべる店を2〜3つ**挙げる。マイナーな店を挙げると「知らない」で終わるので、必ずベタな定番にする。それを「〇〇で買いません」で並べ、最後は「だって、」で切る。本命ブランド名・セール名・割引率は全部コメント欄に回す。

### 5. 連鎖セール型（コメント欄で他ブランドも畳みかける）

> 買いません連呼型の応用。コメント欄で本命のセールを出した後、他ブランドのセールを1つずつ短文で追加投稿していく。本文の連呼のリズムをコメント欄でも続ける形。

**コメント欄の流れ**
```
【コメント1｜本命のセール＋リンク】
サマーセール開催開始ーーっ！！
えっ待って...... 夏本番これからよ？！！

なのに、こんなサマセ神すぎでしょ......
季節外のモノもあるけど、91%OFFはさすがにね......🥺
⇛ 〇〇（pr）

【コメント2｜他ブランド①】
うううっわぁ......！！！

〇〇も500円〜って
エッッッグいサマセやってるぞぉぉ🥺🔥

【コメント3｜他ブランド②】
〇〇も
まだまだ侮れないですよっ🥺
```

**ブロック構造**
- N/X/★：基本形と同じ
- R/D/F：コメント1で本命セール＋リンク
- 追撃：コメント2以降で他ブランドを1投稿1ブランド、2〜3行の短文で連投

**この型が効く仕組み**
本文でやった連呼を、コメント欄では「他のセールも」という形で続けている。読者は1つ読むごとに「まだあるの？」と下へ進むので、滞在時間とリンク接触の機会が積み上がる。感嘆詞とオノマトペ（うううっわぁ／エッッッグい）で熱量を落とさないのがコツ。

**自分のネタで作るには**
同時期に走っているセールを3つ以上ストックしてから投稿する。1つ目は本命（一番踏ませたいリンク）、2つ目以降は割引率が派手で驚きの大きいものを選ぶ。**追撃は1投稿1ブランド、2〜3行まで。**長く書くと途中で離脱する。

## 商品から投稿を作る手順（買いません連呼型）

**ユーザーから商品・セール情報が投げられたら、この順で組み立てる。**

### STEP 1｜商品ジャンルを一言で決める
「夏の服」「こども服」「韓国コスメ」「バームクーヘン」「シュークリーム」のように、**誰でもイメージできる粒度**にする。細かすぎると連呼が効かない。

### STEP 2｜そのジャンルの定番店を2〜3つ挙げる

| ジャンル | 挙げる定番店 |
|---|---|
| レディース服 | ユニクロ / GU / しまむら / イオン / ZARA |
| こども服 | 西松屋 / バースデイ / イオン / GU |
| コスメ・韓国コスメ | LOFT / PLAZA / マツキヨ / Qoo10 / ドンキ |
| スイーツ・手土産 | シャトレーゼ / 治一郎 / ねんりん家 / クラブハリエ / ビアードパパ |
| 日用品・消耗品 | イオン / ドラッグストア / Amazon / 業務スーパー |
| インテリア雑貨 | ニトリ / 無印 / IKEA / セリア / ダイソー |
| キッチン用品 | ニトリ / 無印 / ダイソー / カインズ |

**必ず「みんなが実際に使っている店」を選ぶ。** マイナー店を否定しても誰も引っかからない。

### STEP 3｜連呼の方向を決める
- 商品を1つ売る → **店ずらし**（商品固定・店を変える）
- 買い方そのものを提案する（ふるさと納税・定期便） → **商品ずらし**（店固定・商品を変える）

### STEP 4｜★伏せフレーズを選ぶ
原則「だって、」か「なぜなら、、」。ブランド名を出したい時だけ「〇〇のせいです。だって、」。

### STEP 5｜コメント欄の答えの型を選ぶ

| 答えの型 | 中身 | 向いている商材 |
|---|---|---|
| **セール事実型** | セール名・割引率・対象店舗数・対象ブランド羅列 | セール訴求・期間限定 |
| **こだわり権威型** | 原材料・製法・歴史を箇条書き | 食品・無添加・老舗・こだわり系 |
| **体験ベネフィット型** | 使い方・食べ方・食感の描写 | 単品商品・スイーツ・家電 |
| **仕組み型** | ふるさと納税・定期便・ポイント還元の仕組み | 買い方の提案・日用品 |

# ファミリーC｜ごめん型（短文謝罪フック）

## ごめん型とは

**「ごめん、」で始めて、1〜2行で切る**だけの超短文フック。リアルストーリー型と同じ「マイナスを言いそうでプラスを言う」構造だが、**シーン設定・登場人物・ストーリーを全部そぎ落とした最小形**。説明は本文ではなく**画像が担う**。

```
【本文】（1〜2行／20〜60文字）
「ごめん、」→ 譲歩（〜は認めるんだけど）→ ★「、、、」で切る
※画像は複数枚。商品そのものを見せる

【コメント欄1】
反転＝実は絶賛。多くは「懸念 → 解消」

【コメント欄2】
質問・呼びかけ → 商品リンク（pr / PR）
```

> **リアルストーリー型との使い分け**：目撃談として語れるシーンがある（人が着ている・使っている）ならリアルストーリー型。**商品単体で画が強い**（色違いが並ぶ・形が可愛い・見た目でわかる）ならごめん型。ごめん型のほうが制作コストが圧倒的に低い。

---

## なぜこの型が伸びるのか（ごめん型）

**① 1行目が謝罪なので、何に謝っているのか確かめたくなる**
「ごめん、」だけでは対象も理由も分からない。人は謝罪を見ると**誰に何を謝ったのか**を反射的に探す。情報量ゼロなのにタップ動機だけが立つ、最小コストのフック。

**② 譲歩の「〜けど」が必ず否定を予告する**
「好きなんだけどさぁ」「認めるんだけど」は、日本語の構造上その後に必ず否定が来る。読者は**確定で悪口が来ると信じてタップする**。そして来ない。

**③ 本文が短いほど画像が主役になる**
文字が少ないぶん、タイムラインでは複数枚の商品画像が大きく目に入る。**文章で興味を作らず、画像で興味を作って文章はタップだけ担当する**分業になっている。

**④ 最後のコメントの質問がコメント欄を動かす**
「みんななら何の〇〇欲しい？」「〇〇な人、これ知ってた？」で締めると返信が付く。返信はエンゲージメントとして最も重く、配信が伸びる。

---

## ★譲歩フレーズ集（ごめん型）

「ごめん、」の直後に置いて、否定を予告する。

| タイプ | フレーズ例 | 謝罪の矛先 |
|---|---|---|
| **好きなんだけど型** | 「ごめん、〇〇は好きなんだけどさぁ、、、」 | 商品ジャンルそのもの |
| **認めるんだけど型** | 「ごめんなさい。／可愛い〇〇なのは認めるんだけど、、、」 | 誰にともなく |
| **教えといてよ型** | 「ごめん、〇〇できるなら教えといてよ...／だってこれさぁ、、、」 | ブランド・企業（逆ギレ風） |
| **わかってるけど型** | 「ごめん、いいのは分かってるんだけどさぁ、、、」 | 世間の評価 |
| **語尾だけ型** | 「ごめん。／これはさぁ、、、」 | 不明のまま引く |

### 3原則
1. **本文は2行まで。** 3行以上書くと画像が小さくなり、この型の強みが消える。
2. **語尾は「、、、」か「...」。** 読点を3つ重ねると「言いよどみ」の圧が出る。句点で終えない。
3. **商品名を書かない。** 画像に写っているので説明不要。書くと広告になる。

---

## ブロック構成（ごめん型）

| # | ブロック | 役割 | 置く場所 |
|---|---|---|---|
| **G** | 謝罪 | 「ごめん、」「ごめんなさい。」 | 本文1行目 |
| **Y** | 譲歩 | 「〜は好きなんだけど」「〜は認めるんだけど」 | 本文1〜2行目 |
| **★** | 引き | 「、、、」で言いよどんで切る | 本文の最後 |
| **R** | 反転 | 実は絶賛。「懸念→解消」or「選べない」 | コメント1 |
| **Q** | 質問/呼びかけ | 「みんななら〜？」「〜な人、これ知ってた？」 | コメント2 |
| **F** | CTA | 商品リンク（pr / PR） | コメント2 |

**G → Y → ★ ／ R → Q → F**。リアルストーリー型のS（シーン）とT（対象）が丸ごと無い分、画像がその役を担う。

---

## パターン一覧（ごめん型）

**実例の文言はそのまま使わない。構造とブロックの組み立て方を理解して、自分のネタで作り直す。**

---

### 6. ごめん型（基本形）

> 「ごめん、」＋譲歩の1〜2行だけで切る。コメント1で反転、コメント2で質問を投げてリンクへ。**画像が複数枚あることが前提の型。**

**本文の例（バリエーションA：好きなんだけど型｜1行のみ）**
```
ごめん、絵本モチーフは好きなんだけどさぁ、、、
```

**コメント欄に置く内容**
「こんなの出されたら絶対ひとつになんか選べないじゃーーーん！！！！」＝**選べない＝全部欲しい**という反転 ＋「あと欲を言えば、〇〇もいてほしかったなーーー🥺」＝惜しい点で人間味 → 「みんななら、何の〇〇欲しい？😂」＋ 商品リンク（PR）

> **選べない反転**は色柄バリエーションが多い商品で最強。「1つ選べない」＝「全部いい」を最も感情的に言える。

---

**本文の例（バリエーションB：認めるんだけど型｜謝罪を独立行に）**
```
ごめんなさい。
可愛いレースカーテンなのは認めるんだけど、、、
```

**コメント欄に置く内容**
「バイカラーのポップなやつだから『部屋で浮きまくりそう...』って正直不安だったんよ。」＝**懸念の告白** → 「でもこの『ちょいカラー』、〇〇っぽい空気感あって部屋が一気に垢抜ける天才デザインだわだった👏」＝**解消** → 「パイピングにときめく...」＋ 商品リンク（pr）

> **懸念→解消の反転**は、読者が同じ懸念を持っている商品（派手・クセ強・高い・大きい）で効く。買わない理由を先に潰せる。

---

**本文の例（バリエーションC：教えといてよ型｜二段引き）**
```
ごめん、ユニクロのサングラス度付きに出来るなら教えといてよ...
だってこれさぁ、、、
```

**コメント欄に置く内容**
「形は好きなのに度付きじゃないから諦めてたって人の救世主すぎん？」＝**対象読者の名指し** ＋「レンズ交換できるなら、視力悪い民の夏ちょっと救われるやん...」 → 「ユニクロのサングラス眠らせてる人、これ知ってた？」＋ 商品リンク（PR）

> 謝罪の矛先をブランドに向けた**逆ギレ風**。「教えといてよ」は不満に見えて実は「早く知りたかった」＝最上級の褒め。大手ブランド名を1行目に置けるのでアルゴリズム的にも強い。

---

**コメント欄の締め方（Qブロック）**

最後のコメントは、リンクの直前に**1行の質問か呼びかけ**を置く。これが返信を生む。

| 締め方 | 例 | 狙い |
|---|---|---|
| **選ばせる質問** | 「みんななら、何の〇〇欲しい？😂」 | 返信でコメント欄が動く |
| **該当者への呼びかけ** | 「〇〇眠らせてる人、これ知ってた？」 | 自分事化＋クリック |
| **ときめき一言** | 「〇〇にときめく...」 | 余韻。感情だけ残す |

**ブロック構造**
- G：「ごめん、」「ごめんなさい。」で入る
- Y：譲歩で否定を予告する（〜けど／〜けどさぁ）
- ★：「、、、」で言いよどんで切る。**ここまで20〜60文字**
- R：コメント1で反転。「懸念→解消」か「選べない」か「救世主」
- Q：コメント2の1行目に質問・呼びかけ
- F：商品リンク（pr / PR）

**この型が効く仕組み**
謝罪＋譲歩というたった2要素で「この後に否定が来る」と100%予告できる。読者は否定を確認しにタップし、そこにあるのは絶賛なので好感に変わる。**リアルストーリー型と心臓は同じだが、ストーリーを作る手間がゼロ。**そのぶん画像の質が成否を分けるので、色違い・柄違いが並ぶカットや、商品の形が伝わるカットを複数枚用意する。

**自分のネタで作るには**
まず**画像で興味が作れる商品か**を判断する。色柄が複数ある／形が特徴的／見た目で用途がわかる、のどれかに当てはまればこの型が使える。当てはまらない（見た目が地味・機能が売り）ならリアルストーリー型か買いません連呼型を選ぶ。

本文は「ごめん、」＋譲歩1つで完成。**シーンも登場人物も値段も書かない。** コメント1では読者が抱きそうな懸念を先に自分が言い、それを解消する形で褒める。最後は必ず質問か呼びかけで締めてからリンクを置く。

# ファミリーD｜固有名詞直球型（ブランド名フック）

## 固有名詞直球型とは

**有名ブランド名を1行目に置いて、そのまま感嘆・称賛で切る**シンプルな型。まだタイムラインで見かけていない新作・コラボ・新カラーを、いち早く紹介する。

```
【本文】（1〜2行）
ブランド名（固有名詞）→ 感嘆・称賛 → 「...」で切る
※商品画像を複数枚

【コメント欄】
追加の褒め（色展開 / 質 / センス）→ 商品リンク（pr / PR）
```

---

## ⚠ 位置づけ：伸び率は他の型より低い

**この型は本ファイル内で最も伸び率が低い。** 実測でも他ファミリーに届いていない。

| 型 | 表示数の実測レンジ |
|---|---|
| リアルストーリー型 | 24万〜165万 |
| 買いません連呼型 | 17万〜53万 |
| ごめん型 | 10万〜24万 |
| **固有名詞直球型** | **6,305〜10万** |

**理由：★引き（マイナス予感）が無いから。** 「可愛すぎた...」「本気感じるわ...」は褒めているだけなので、読者は本文だけで満足してタップしない。タップされなければコメント欄のリンクにも届かない。

### だから、こう使う
- **メインの型にしない。** リアルストーリー型・ごめん型を主軸にして、この型は埋め草・投稿頻度の維持に使う。
- **新規性が命。** まだ誰も投稿していない新作・コラボ・新色を最速で出す時だけ価値が出る。出尽くした商品でこの型を使うと数字が出ない。
- **語尾にぼやきを足すと伸びる**（後述）。

---

## この型が持つ唯一の強み

**固有名詞が配信を運ぶ。**
Threadsはブランド名・商品名などの固有名詞に反応しやすい。ビルケン／adidas／ティファニー／アシックスのような**誰でも知っているブランド名**を本文に置くと、そのブランドに興味がある層へ配信が乗る。ストーリーを作らなくても最低限の露出が確保できる。

つまりこの型は「**フックの弱さを固有名詞の力で埋めている**」構造。だから固有名詞が弱い（無名ブランド・一般名詞）と、何も残らない。

| # | ブロック | 役割 | 置く場所 |
|---|---|---|---|
| **P** | 固有名詞 | ブランド名。できるだけ**1行目の頭**に置く | 本文 |

### ぼやき（W）を足すと数字が変わる

実測で最も伸びた投稿（10万）だけ、称賛のあとに**買えない事情のぼやき**が付いている。

```

  靴箱置くとこないのに......ﾎﾞｿﾎﾞｿ     ← ぼやきあり／10万

✕ さすがHender Scheme可愛すぎた...      ← 褒めて終わり／6,305
```

**「置く場所ないのに」「お金ないのに」「持ってるのに」**は、否定に見えて**買う前提のぼやき＝欲しさの最大表現**。マイナス予感の代わりになり、この型の弱点を部分的に埋める。**この型を使うなら必ず入れる。**

| ○ 強い | × 弱い |

# ファミリーE｜後悔・警告型（自己体験フック）

## 後悔・警告型とは

**自分が買った体験を「買わないほうがいい」「後悔してる」と否定から語り**、コメント欄で「良すぎて手放せない＝実質最大級の推薦」に反転させる型。リアルストーリー型（他人の目撃談）と違い、**語り手＝自分**。ネガティブ予感の中で最も引きが強い。

```
【本文】（40〜120文字）
否定・警告・後悔で言い切る → ★「なぜなら、」「だってさ」で理由を伏せて切る

【コメント欄1】
反転＝「悪いんじゃなく、良すぎる」/ 沼った理由 / 具体的な良さ

【コメント欄2】
使用シーン・注意点（本物の弱点でなく愛ゆえの一言）→ 商品リンク（pr）
```

> **実測21万〜35万。** 定番ブランド（特にモンベル/mont-bell系）×警告フックは再現性が高い。**主軸に据えてよい強さ。**

---

## なぜこの型が伸びるのか（後悔・警告型）

**① 否定100%だから確実に足が止まる**
「マジで買わないほうがいい」「まっっっじで後悔してる」は、褒め投稿と真逆で**確定でネガティブ**。読者は「なんで？」「地雷なの？」と反射的に理由を探す。ネガティブ予感系の中でも最上位の停止力。

**② バズってる商品への"逆張り"が目を引く**
「バズってる〇〇、やっと買ったのに…」は、**世間の絶賛に水を差す**構図。同調を裏切るので強く止まる。

**③ 自分の体験だから信頼される**
他人の目撃談より「私が実際に買った」の方が生々しい。**買うか迷っている読者と同じ立場**から語るので、反転後の推薦が刺さる。

**④ 反転の落差が最大級**
「買うな」→「良すぎて手放せない」の落差は、この型でしか出せない。読者は「なんだ、褒めてるのか」と安心し、そのまま欲しくなる。

1. **否定を言い切ってから切る。** 「〜ほうがいい。なぜなら、」「〜のに…」で止める。予感でなく断言でいい（コメントで必ず反転するから）。

3. **バズ商品・定番ブランドと相性がいい。** 「バズってる」「みんな絶賛の」を付けると逆張り効果が乗る。
