# かぴ式 投稿パターン集

> **用途**: /kapi-writer でコメント誘導型の投稿を生成するとき参照するパターン集。
> 各パターンは「元ネタ構造」から抽出した型骨格。フレーズではなく構造を使う。
> **読む順番**: kapi-writing-rules.md → kapi-first-lines.md → このファイル。
>
> **実例の文言はそのまま使わない。構造とブロックの組み立て方を理解して、ちゃむペルソナで作り直す。**

---

## コメント誘導型とは

本文で興味を引いて、コメント欄に続き（詳細）を置く構造。Threadsで最も伸びやすい基本形。タップを生むための構造。

```
【本文】（100〜500文字）
フック → 主張 or 価値の提示 → 本文を「、」で切る

【コメント欄】（制限なし）
本文の続き / 詳細解説 / 根拠 / 具体例
```

コメント欄の繋ぎ方の原則（本文の続きとして書く／結果から入る／商品名は最後）は **kapi-writing-rules.md** に集約。ここでは各型ごとの「コメント欄に置く内容」＝素材だけを扱う。

---

## ブロック構成

各型の構造は、以下のブロック記号で示す。

| # | ブロック | 役割 |
|---|---|---|
| **A** | フック | スクロールを止める1行目 |
| **B** | 主張 | 言いたいことの核 |
| **C** | 理由 | なぜそう言えるか |
| **D** | 補強 | 主張を支える材料。権威・数字・ロジック・リスト |
| **E** | 転換 | 読者側に寄り添う。ハードル下げ・共感 |
| **F** | 締め/CTA | 行動を促す or コメント欄へ誘導 |

※ コメント誘導型では、本文の末尾を「、」や「↓」で切って、続きをコメント欄に置くのが基本。

## K-01 専門家耳打ち型

### 元構造の分析

元投稿：「皮膚科の先生が僕にしか聞こえない声で......（サリチル酸・マンデル酸の解説）使い始めてから鼻がツルツル→なのに突っ張らない」

**なぜ伸びる型か：**
- 「自分だけに教えてくれた」という特別感で掴む
- 難しい専門用語が入ることで「本当に効く理由がある」という信頼を作る
- 「難しすぎたから聞き直した」というユーモアで自分ごと化させる
- 「なのに〜」という逆説で追加ベネフィットを入れて締める

### 骨格

```
1行目（フック）
「[専門家の種類]が[自分だけ感を演出する状況]で......」

2行目（専門情報）
「[専門用語A]で[効果A]、[専門用語B]で[効果B]すれば[結果]になるよ」って😳

3行目（ユーモア・自分ごと化）
「難しすぎたからもう一回聞いた🤣」
（または：「日本語で言ってってなった🤣」「何言ってるか全然わからなくて笑」）

4行目（体験談）
「使い始めてから[具体的な変化①]
[具体的な変化②]...
なのに[逆説的な追加ベネフィット]🥳」

↓（コメント欄へ誘導・ここで本文を止める）
```

### 使い方

**ステップ1：専門家を決める**
- ちゃむのジャンルに合った専門家を設定する
  - 美容系：皮膚科医・美容師・エステティシャン
  - 育児系：小児科医・保育士・助産師・栄養士
  - 健康系：薬剤師・整体師・栄養士

**ステップ2：「自分だけ感」の演出**
使える表現例：
- 「〜が僕にしか聞こえない声で......」
- 「〜の先生に聞いたら小声で教えてくれた」
- 「〜に直接聞いてみたらこっそり教えてくれた」

**ステップ3：専門用語の入れ方**
- 実在する成分名・技術名・メソッド名を入れる（作らない）
- 商品ページや公式サイトの情報を根拠にする
- 断定形で書いてOK（「〜すれば綺麗になるよ」）。ただし医療効果の断定は禁止

**ステップ4：ユーモア行の選択**
- 「難しすぎたからもう一回聞いた🤣」（基本形）
- 「日本語で言ってってなった🤣」
- 「何言ってるか全然わからなくて笑った」
- ※難しい用語を入れた場合のみ使う。専門用語がない場合はスキップ

**ステップ5：体験談の構造**
```
使い始めてから[変化A]
[変化B]...
なのに[意外なベネフィット]
```
「なのに」の部分が重要。「普通こうなりそうなのに逆」という逆説が信頼感を上げる。

例：
- 「なのに全く突っ張らない」（保湿なのに重くない）
- 「なのに赤みが出ない」（酸系なのに刺激がない）
- 「なのに子どもが嫌がらない」（薬っぽいのに使いやすい）

### コメント欄の構成（アフィリ使用時）

```
コメント欄1（返信1）：
[専門用語の言い換え説明]
[商品の特徴・使い方・対象者の詳細]
[使った量・頻度・期間など具体的な補足]

コメント欄2（返信2）：
[ベネフィット型CTA 1行]↓
PR　Rakuten
[楽天アフィリエイトURL]
```

### 注意事項

- 専門家の発言は実際に確認できる情報のみ（完全に作らない）
- 医療効果・治癒の断定は禁止（「改善した」→「気になっていた〇〇が変わった」）
- 体験談はちゃむの実体験として書く。実体験がない場合は「使ってみたら」調に留める
- 「皮膚科の先生が〜」などの専門家の言葉をそのまま流用しない。商品・文脈に合わせて作り直す

### 実例（ダニシート版・2026-10作成）

**本文（投稿）**
```
赤ちゃんの布団のダニ、スプレーだけで済ませてたパパママへ。
暗い所が好きなダニは、布団の表より裏側に潜ってるらしい。だから貼る場所は、裏。
```

**コメント欄1（内容詳細）**
```
元保育士の私も、裏側って聞いて「え、表じゃないの？」ってなった。
貼るのは布団1組につき4カ所。1枚で畳1枚分の範囲で、使用目安は3か月。
殺虫剤を使わないタイプで、貼るのは布団の裏側。赤ちゃんの手が届かないのも安心できた。
即効性はないけど、毎晩の布団に入る気持ちが軽くなった（個人の感想です）。
```

**コメント欄2（CTA＋URL）**
```
ダニのことが気になりだしたら↓
PR　Rakuten
[URL]
```

## 1. 断言連呼型

> 同じ型の言い切りを2〜4回続けて畳みかけ、最後の1行だけトーンを変えて着地する。反復のリズムが目を引き、読み込まなくても勢いだけで止まる。言い切りは肯定でも否定でもよく、定番を否定で並べると常識破壊のギャップも乗る。

**本文の例（バリエーションA：属性別の連呼）**
```
10億回は言うけど...

イエベ春は黙って「〇〇 ミルクティー」
イエベ秋は黙って「〇〇 スコッチ」
ブルベ夏は黙って「〇〇 キャンディ」
ブルベ冬は黙って「〇〇 タロ」

リップ難民卒業！塗った瞬間、垢抜ける！！
```

コメント欄に置く内容：リップはこれ買っとけば間違いなし！！＋ 商品リンク（PR表記）

**本文の例（バリエーションB：同一フレーズの三連打）**
```
マジで色気付きたいイエベ！！聞いて！！

『チークは黙って〇〇のC04！！』
『チークは黙って〇〇のC04！！』
『チークは黙って〇〇のC04！！』

塗った瞬間、即垢抜け！色気たっぷり...
```

コメント欄に置く内容：薄づきで使用感が最高。サイズ感などの一言補足 ＋ 商品リンク（PR表記）

**本文の例（バリエーションC：宣言連打からのオチ）**
```
【ご報告】

〇〇で、夏の服買います！
〇〇で、秋の服買います！
〇〇で、全っ部買います！

だって...80%OFFしてるからぁああ
```

コメント欄に置く内容：普段は高くて手が出ない、という本音 ＋ 買えて嬉しい気持ち ＋ 商品リンク（PR表記）

**本文の例（バリエーションD：否定連呼＋常識破壊）**
```
【ご報告】
夏の服は、〇〇で買いません。
夏の服は、〇〇で買いません。
夏の服は、〇〇でも買いません。

〇〇のせいです。だって、
```

コメント欄：セール情報（割引率）を出す ＋ 他ブランドのセールも「〇〇も500円〜」と次々に羅列 ＋ 商品リンク（PR表記）

**ブロック構造**
- A：念押し・呼びかけ・宣言のいずれかで前置きを作る（「10億回は言うけど」「聞いて！！」「【ご報告】」）
- D：同じ構文を2〜4回そのまま繰り返す。対象（属性・季節・シーンなど）だけを差し替える
- C/F：最後の1行だけ言い回しを変え、理由づけ・ベネフィット・余韻のどれかで締めてコメントへ流す

**自分のネタで作るには**
言いたい結論を1つの文型に固定し、対象だけを差し替えて2〜4回そのまま繰り返す。表現を毎回変えず、同じ言葉を畳みかけること自体を熱量の演出として使う。最後の1行だけ数字やオチを足して締め、詳しい説明・スペック・リンクはすべてコメント欄に回す。

## 2. 怒り構文

> 怒りの絵文字と「誰ですか」の詰問から入るが、中身は感謝。ギャップで足を止めさせ、最後に怒りを好意へ反転させて切る。

**本文の例（バリエーションA：家事ネタ）**
```
もう、誰ですか💢
〇〇すると〇〇が消えるって言った人は💢
〇〇したら、まさかの〇〇💢
でも〇〇なくらいに〇〇になった💢
ほんとありがとう💢スレッズ愛してる💢
やり方は、
```

コメント欄に置く内容：実際に試した手順を数字つきで具体的に → 想定外だった結果の再現描写 → やってみて気づいた追加のお得ポイント → 商品リンク（PR表記）

**本文の例（バリエーションB：育児ネタ）**
```
あのさ💢！？誰なんですか！？💢
〇〇があれば子どもが〇〇するって言った人は💢！？
買ったけどまっっじで〇〇だったわ！！！
〇〇時間ずっと〇〇してる！！！
でもぶっちゃけさ、
```

コメント欄に置く内容：「もっと早く知りたかった」という後悔の一言 → 実際の使用シーンでの効果 → 助かっている理由 → 商品リンク（PR表記）

**ブロック構造**
- A：怒りの絵文字＋「誰ですか／誰なんですか」で、発信者不明の情報を責める体から入る
- B：その情報どおりに試した報告。当初の想定を超える結果を怒り口調のまま語る
- D：怒り絵文字を連打しながら効果・驚きを畳みかける
- F：「ありがとう」「でもぶっちゃけさ」で怒りから好意へトーンを反転させて切る → コメントへ

**自分のネタで作るには**
「〇〇と言った人は💢」で情報源をぼかしたまま怒りの体で入り、実際に試したら想定を超えて良かった、という展開にする。感情のピークで怒り絵文字を連打し、最後の1行だけ「ありがとう」や「ぶっちゃけ」でトーンを反転させて余韻を残す。具体的な手順や数字はすべてコメント欄に譲る。

## 3. 箇条書き型

> 保存したくなる情報を箇条書きで一気に並べる。前置きで保存を促し、リストの途中で切ってコメント欄に残りとまとめを置く。全ジャンルに転用できる、最も汎用性の高い型。
>
> ※ 項目は5〜10個が目安。本文に半分だけ載せ、残りはコメント欄に回す。

**バリエーションA：ランキングカウントダウン**
```
【ぶっちゃけ効果凄かった】やってよかった習慣 TOP10〜1位

10位　夜のマグネシウム（寝つき爆速＆翌朝のむくみ激減）
9位　まつ毛美容液（本数増えた気がする）
8位　ゆる糖質オフ（小さな吹き出物が出にくくなった）
7位　毎日オメガ3（パサつき髪がしっとり落ち着いた）
6位　白湯を朝一で飲む（胃腸が整って肌のくすみが軽い）
```

コメント欄：5位〜1位を続ける ＋「気になるものから順番にやるのがコツ」の一言

**バリエーションB：やるべき／やめるべきの対比**
```
3ヶ月で9kg落としたので、はっきり言うよ。本気で落とすなら、
❌やるべきじゃない
・スクワット毎日100回
・有酸素運動だけひたすら頑張る
・着圧ソックスで誤魔化す
（〜10個並べる）
⭕これはやるべき
```

コメント欄：⭕のリストを並べる ＋ 実体験の一言 ＋ フォロー誘導

**バリエーションC：比喩ラベル型**
```
お願いです。必ず保存してください！

・かかと落としは「骨への刺激スイッチ」
・片足立ちは「転倒予防の1分トレ」
・3秒スクワットは「ながらでできる筋トレ」
（〜10個並べる）
特にやった方が良いのは...
```

コメント欄：特に推す項目を数個ピックして深掘り ＋ まとめ

**バリエーションD：悩み→原因のマッチング**
```
お願いです。大切なのでメモしてください。

肌荒れ → タンパク質不足
乾燥が止まらない → オメガ3不足
くすみ → 鉄分不足
大人ニキビ → 亜鉛不足
毛穴が目立つ → ビタミンA不足
目の下のクマが消えない →
```

コメント欄：残りのペア ＋ 専門家としての一言 ＋「〇〇は仕上げ、△△が土台」のようなまとめ

**ブロック構造**
- A：保存・記憶を促す前置き（「必ず保存してください」「そろそろ覚えてください」「メモしてください」）
- D：箇条書きで5〜10項目。本文には半分だけ置く
- 切断：最後の項目の途中、または「特に〜は」「⭕これはやるべき」でコメントへ流す
- コメント欄：残りの項目 ＋ 専門的な補足や格言的まとめ ＋ 保存・フォロー・固定投稿への誘導

**自分のネタで作るには**
自分の専門や体験から「悩み一覧」か「やってよかったこと一覧」を5〜10個出す。前置きで保存を促し、本文には半分だけ載せて残りはコメント欄へ回す。各項目は1行で言い切り、余裕があれば独自ネーミングや「悩み→答え」の形にすると刺さりが強くなる。

## 4. 知らなきゃ損型

> 「知らずに損していた」という情報格差の告白から入り、お得な制度・裏技を数字つきで解説する。最後に本題と関連する別の商品へ、緊急性のあるお願い口調で橋渡しする。

**本文の例**
```
ほんっとスレッズありがとう！！！〇〇したら〇〇って知らなかった😭😭😭
私これ知らなくて、普通に〇〇だけ払ってた、、、
```

コメント欄に置く内容：制度・裏技の仕組みを具体的な数字つきで説明 → 「つまり実質〇%相当」と言い換え → 手順を「①→②→③」でシンプルに → 本題と関連する別の困りごとへ橋渡し（「お願いだから〇〇だけは」）→ 商品リンク（PR表記）

**ブロック構造**
- A：感謝＋衝撃の告白（「ほんっとスレッズありがとう」「〇〇って知らなかった😭」）で情報格差を自分ごとに開示
- B：知らなかった制度・裏技の存在を明かす
- D：数字つきの仕組み解説 → 用意するもの・手順の箇条書き
- F：本題の関連悩みへ話をずらし、心配・緊急性で背中を押して商品へ誘導

**自分のネタで作るには**
「〇〇したら〇〇だった、知らなかった」という情報格差を自分の実体験として最初に置く。具体的な数字と手順は惜しみなく出し切り、読み手が実際に真似できるレベルまで書く。最後の1枚で本題と関連するけれど別の困りごとを持ち出し、そこに紹介したい商品を添える。

## 5. 禁止フック型

> 「〇〇はやめてください」という禁止・否定で始め、大多数が正しいと思っている常識をひっくり返して驚かせる。理由は言いかけて切り、コメント欄で「なぜダメか → 正しいやり方」を解説する。

**本文の例**
```
『5と0のつく日』に気合い入れるの、やめてください。正確に言うと、当日に気合い入れても遅い！！5と0のつく日って、みんなが投稿するから、当日にバズ投稿を出しても普通に埋もれます。朝から本気の投稿を作り始めてる人、残念だけどタイミングがズレてます。なんでかっていうと、
```

コメント欄に置く内容：否定の根拠を明かす → 正しいやり方を真似できる具体的な形で提示 → 早く動く動機づけで締める

**ブロック構造**
- A：禁止・否定フック（「〇〇するの、やめてください」）で指を止める
- B：常識のひっくり返し（多くの人が正しいと思っている行動を否定して「え、そうなの？」を作る）
- C：危機感の描写（「このままだと損する／ズレている」を具体化）
- F：理由を焦らして切る（「なんでかっていうと、」でコメント欄へ）

**穴埋めテンプレート**
```
[常識的な行動]、やめてください。正確に言うと、[もっと鋭い否定]！！
[なぜダメか・このままだとどうなるかの危機感]。
[当てはまる人への一言（残念だけど〜）]。なんでかっていうと、
```

**自分のネタで作るには**
冒頭は否定・禁止で始める。否定する対象は、自分のジャンルで「誰もが当たり前だと思っている常識」を固有名詞・具体的な行動レベルまで落とす。理由は「なんでかっていうと、」等で切ってコメント欄へ。コメント欄で「なぜダメか → 正しい行動 → 早く動く動機づけ」を、真似できる具体で示す。

---

## 6. 断言型

> 読者に「ある行動をやるべき」と提案し、そのメリットを畳みかける。最後に読者が抱く懸念を先読みして途中で切り、コメント欄へ誘導する。

**本文の例**
```
大声で言う。楽天アフィリエイトしてる人は、Amazonアソシエイトもした方がいい。楽天で紹介してる商品はだいたいAmazonにも売ってる。リンクを2つ貼るだけで取りこぼしてた層からも報酬が入る。しかもAmazonは無料体験の紹介でも報酬が出て、Audibleなら1件1,500円、Kindleやらくらくベビーも狙える。これで月20万以上稼いだ知人もいる。絶対した方がいい。でも「審査あるんよね？不安」って思ってる人いると思うけど、
```

コメント欄1：懸念を即否定（「〇〇なら大丈夫」）→ 具体情報を①②③の番号で提示 → 最大の不安ポイントを再度拾って次コメントへ引っ張る
コメント欄2：他媒体・他手段との比較で優位性を補強 → 自分の実体験で結論を後押し → 質問受付で締める

**ブロック構造**
- A：断言フック（「大声で言う。」）で、重要なことを言うと宣言して指を止める
- B：ターゲット指定（「〇〇してる人は」）で、誰に向けた話かを明示して自分ごと化させる
- C：べき提案（「〇〇もした方がいい」）で、やるべき行動を断定で示す
- D：メリットを2〜3個畳みかける（できれば数字入り）
- E：具体的な成果で権威付け（「月20万以上稼いだ知人もいる」など数字で説得力）
- F：懸念を先回りして切る（「でも『〇〇が不安』って思ってる人いると思うけど、」でコメントへ）

**穴埋めテンプレート**
```
[フック]。[ターゲット]は、[べき提案]した方がいい。
[メリット①]。[メリット②]。[メリット③]。
[具体的な成果や数字で権威付け]。
絶対した方がいい。でも「[読者が抱く懸念]」って思ってる人いると思うけど、
```

**自分のネタで作るには**
「今やってる行動＋もう1つ足すべき」の形が特に強い。メリットは必ず具体的な数字を入れる。ターゲットが「でも〇〇が不安／面倒」と思うポイントを1つ選び、本文の最後に置く。その答えをコメント欄に用意する。コメント欄は「番号で具体化 → 実体験で後押し → 質問受付」の3点セットで締める。

---

## 7. 消去法型

> みんなが「正解はこれ」と思い込んでいる定番の候補を複数並べて次々に否定し、本当の答えは言わずに切る。「じゃあ何が正解？」をコメント欄で回収する。
>
> ※ 禁止フック型（5）が「〇〇はやめて」という命令なのに対し、こちらは候補を並べて消していく形。

**本文の例（バリエーションA：命に関わる系）**
```
何度でも言う。地震の時に必要な物って「3日分の食料」でも「浄水器」でも「家具固定」でもない。大地震で本当に命に関わるのは、
```

コメント欄：意外な正解 ＋ なぜそれが最重要かの理由 ＋ 商品リンク（PR表記）

**本文の例（バリエーションB：権威者から聞いた系）**
```
〇〇で月50万稼ぐ人が教えてくれた『はじめの10万を作るのに最も大事なこと』にビビった。『〇〇』でもなく、『〇〇』でもなく、『〇〇』でもなく、1番大切なのが、
```

コメント欄：意外な正解 ＋ その理由 ＋ 念押し

**ブロック構造**
- A：断言 or 権威づけの前置き（「何度でも言う」「〇〇で稼ぐ人が教えてくれた」）
- B：テーマ提示（何についての話か）
- D：みんなが正解だと思っている候補を「〇〇でもなく」で2〜4個、否定で畳みかける
- F：本当の答えは言わず「本当に大事なのは、」「1番大切なのが、」で切ってコメントへ

**自分のネタで作るには**
自分のジャンルで、みんなが「これが正解」と信じている候補を2〜4個挙げ、「〇〇でもなく、〇〇でもなく」と順に否定する。否定する候補は、その分野の人が実際に真っ先に思いつく具体的なものにする。本当の答えは本文で絶対に言わず、「本当に大事なのは、」で切ってコメント欄に置く。答えは意外性があるほど刺さる。

---

## 8. 権威性型

> 「誰が言っているか」で信頼を作ってから中身を出す。冒頭に実績・資格・著名人の名前を置くことで、そのあとの主張や商品紹介がすべて「信じてよさそうな情報」に変わる。
>
> ※ 権威づけは単体でも使えるが、断言型（6）・消去法型（7）などと重ねると特に強い。

**バリエーションA：自分の実績で権威（番号付き多スレッド）**
```
13年間〇〇が出てないわが家の対策6選！！
真似してくれればガチで〇〇！！！！
```

コメント欄（スレッドを継続）：①〜⑥を1つずつ紹介。各項目に使う場所・使い方まで具体的に書き、商品リンクを1つずつ添える（PR表記）

**バリエーションB：資格・肩書きで断言**
```
看護師として断言する。〇〇になりたくなければ①〇〇②〇〇③〇〇より大切なことが2つあります。その2つは、
```

コメント欄：意外な正解2つ ＋ なぜそれが土台になるかの専門的なメカニズム ＋ 裏付けの数字

**バリエーションC：著名人・第三者の借用**
```
〇〇（著名人）が言ってた「〇〇」をやってみたら、〇〇がまさかの〇〇で驚いた。〜だからちゃんと伝わるんだよね。ママ友に教えたら次の日
```

コメント欄：「〇〇の本買ったわ」などの反響 ＋ 関連書籍・商品リンク（PR表記）

**ブロック構造**
- A：権威の提示（実績の数字／資格・肩書き／著名人の名前）で「この人の言うことは信じられる」を作る
- B：主張・ノウハウのテーマ提示
- D：権威を裏付ける具体（番号付きノウハウ／専門的メカニズム／体験談）
- F：続き・正解・商品はコメント欄へ

**自分のネタで作るには**
自分が使える権威を1つ選ぶ。①長年の実績や具体的な数字、②資格・職業・肩書き、③有名な専門家の名前、のどれか。それを冒頭に置いてから主張を出す。資格がなければ「〇〇が言ってた」と第三者を借りればいい。裏付けは数字や具体的なメカニズムで補強し、商品や正解はコメント欄に回す。

ちゃむの場合：「保育士16年」「元保育士・3児の母」が使える権威。小児科医・栄養士など育児系専門家の借用も有効。

## 9. ノウハウ連打型

> 「〇〇1年生」などターゲットを絞り、短いコツを『』で次々に連打する。各コツに『←具体例』をその場で添えることで、抽象論で終わらせず「すぐ使える」に変える。初心者のフォロワー化に強い。
>
> ※ 箇条書き型（3）と近いが、こちらは「コツ＋その場の具体例」のペアを高速で畳みかけるのが特徴。

**本文の例**
```
聞こえますか...朝早くから頑張ってる...
〇〇1年生のみなさま...

『本文にリンクは絶対貼っちゃだめ』『あとメンションもダメ』『#タグはいらないよ』『〇〇じゃなくて、〇〇（固有名詞で）』『←こんな感じで、ブランド名や商品名、固有名詞を入れて』『冒頭1行目は、
```

コメント欄に置く内容：残りのコツを『コツ』＋『←具体例』のセットで続ける → 「まずはこれを頭に入れるだけで全然違う」というまとめ → 読者に寄り添う一言で締める

**ブロック構造**
- A：呼びかけ＋ターゲット指定（「聞こえますか」「〇〇1年生のみなさま」）で、対象を絞って自分ごと化させる
- D：短いコツを『』で連打。1つ出すごとに『←具体例』をその場で添える
- F：本文の途中（「冒頭1行目は、」など）で切ってコメントへ

**自分のネタで作るには**
自分のジャンルの初心者が最初につまずくコツを5〜10個出す。各コツは1フレーズで言い切り、必ず『←具体例』をペアで添えて抽象論にしない。冒頭でターゲットを名指しし、本文は途中で切って残りをコメント欄へ。最後は「これだけで変わる」＋寄り添いの一言で締める。

---

## 10. 一行フック型

> 本文を1行だけの強い断言・警告にして、詳細をすべてコメント欄に置く。極端に短いからこそ「え、何？」で全員がコメントを開く。
>
> ※【最重要】コメント欄の中身が「当たり前のこと」だと、開いた読者をがっかりさせて逆効果。必ず意外な情報・見落としがちな盲点を置く。当たり前のことしか書けないネタでは、この型は使わない。

**本文の例**
```
〇〇、これするとアカウント停止されます。
```

コメント欄に置く内容：
- 「これです↓」の一言 → 該当する行動・原因を箇条書きで列挙
- さらに「大手でも間違えがちなのが、」と、意外な盲点を1つ最後に持ってくる

**ブロック構造**
- A：1行で完結する強い断言・警告（「〇〇、これするとアカウント停止されます」）
- 切断：本文はこの1行だけ。説明を一切せずコメントへ丸投げ
- コメント欄：D 詳細を箇条書き ＋ 最後に「見落としがちな盲点」を1つ足す

**自分のネタで作るには**
伝えたいことを1行の断言・警告に圧縮する。本文では理由も詳細も一切書かない。コメント欄には、読者が「知らなかった」と感じる内容を用意する。当たり前のことしか書けないなら、この型は選ばない。締めに「実は大手でもやりがちな盲点」を1つ入れると効果が跳ねる。

---

## 11. 擬人化比較型

> 複数の対象を「〇〇 ← ひとことキャラ紹介」という同じ型で並べ、それぞれにギャップ（表の顔と実態のズレ）を効かせる。全体を1つの世界観の比喩で統一すると、比較そのものが1つのネタとして回覧される。

**本文の例（育児・アフィリ応用版）**
```
西松屋 ← 安さは正義。でも気づけば毎週通ってる沼系
アカチャンホンポ ← 品揃え最強。でも財布が軽くなる課金圧つよめ系
バースデイ ← しれっと神アイテムが紛れてる、当たり外れの宝探し系
```

コメント欄：「結局ここで買うのが正解だった」＋ おすすめ商品リンク（PR表記）

**ブロック構造**
- 「対象名 ← キャラ紹介」の同一フォーマットを3つ以上並べる
- 各行を「表の顔 → 裏の落差（ギャップ）→ 〇〇系〇〇」で統一する
- 面白さで完結させる（CTA不要）か、コメント欄に本命＋商品リンクを置いてアフィリにつなげる

**自分のネタで作るには**
比較したい対象を3つ以上選び、「対象名 ← 〇〇だけど〇〇な〇〇系〇〇」という型を1つ決めて、崩さずに並べる。肝は各行に必ずギャップ（期待と実態のズレ）を入れること。アフィリにつなげるなら、本文は面白さで引きつけ、本命や商品リンクはコメント欄に置く。

---

## 12. 体験談ストーリー型

> 自分の実体験を物語として語り、続きをコメント欄に置く。「欲しい結果を先出し → 権威に教わる → 半信半疑で試したら効果」の流れや、「素朴な疑問 → まさかの答え → 正体を伏せて切る」の流れなど、体験のストーリーで引き込む。

**バリエーションA：権威に教わって半信半疑→効果**
```
〇〇になれます。〇〇の専門家に「〇〇する方法ないか」って聞いたら「〇〇しろ。それを1日3回」って言われた。半信半疑で毎日続けた。3週間後、〇〇になった。先生に報告したら、追加でこんなことも、、、
```

コメント欄：教わった方法の仕組みを専門的に解説 ＋ 権威をもう一段重ねる ＋ 手軽さを強調 ＋ フォロー誘導

**バリエーションB：素朴な疑問→まさかの答え→正体隠し**
```
〇〇の店員さんに「なんで〇〇って〇〇なんですか？」って聞いたら、まさかの答えが…。「これ入れてるんですよ」って教えてくれたのが、〇〇でめっちゃよく見るアレだった…
```

コメント欄：正体を明かす ＋ 自分で試した体験 ＋ 手軽さ ＋ 商品リンク（PR表記）

**ブロック構造**
- A：強いベネフィットの断言（バリA）／素朴な疑問＋「まさかの答えが…」（バリB）で掴む
- B/D：権威に教わった設定でメソッド提示、または正体を「アレ」と伏せて提示
- ストーリー：半信半疑 → 試した → 効果、を自分の実体験として語る
- F：「追加でこんなことも、、、」「〜アレだった…」など、続きや正体を伏せて切ってコメントへ

**自分のネタで作るには**
まず読者が一番欲しい結果をベネフィットとして冒頭に置く（バリA）。または、みんなが薄々気になっている素朴な疑問を入り口にして、答えを「アレ」と伏せる（バリB）。次に「専門家・詳しい人・店員に聞いたら〜と言われた」という形で提示し、自分が試した流れを実体験として語る。肝心の一点（追加ノウハウ／商品の正体）だけは伏せて切り、コメント欄で明かしてフォロー誘導や商品につなげる。

補足：身体・健康効果の断定（「必ず〇〇になる」等）は禁止。「〇〇になった気がする」「私はこう変わった」の主観トーンに収める。

## 13. 教えてもらったシェア型

> 「〇〇で働く姉／薬剤師の親友が教えてくれた」と身内・知人の権威を借り、意外な豆知識やお役立ち情報を"広めたい"トーンで共有する。最後にさりげなく商品へつなげるので押し売り感がない。
>
> ※ 権威性型（8）の身内・知人バージョン。「シェアしたい豆知識」＋「ついで販売」に特化した形。

**バリエーションA：業界の内情トリビア**
```
〇〇で働く姉が教えてくれたんだけど、〇〇って実は〇〇なんだって。〜らしい！「え、じゃあ〇〇ってどこで〇〇できるん？」って聞いたら、
```

コメント欄：姉が教えてくれた答えを数個 ＋「知っておくと〇〇選びが面白くなる」＋「ついでに〇〇も教えてくれたから載せとく」＋ 商品リンク（PR表記）

**バリエーションB：悩み解決のお役立ち**
```
もっと広まって欲しい……〇〇で子どもが〇〇になったら、『〇〇』の出番だよ！当時〇歳の息子に、薬剤師の親友が教えてくれた！！！〇〇するんだけど、
```

コメント欄：効果・仕組みの解説 ＋ 使えるシーンや月齢の補足 ＋ 実体験 ＋ 商品リンク（PR表記）

**ブロック構造**
- A：身内・知人の権威＋「教えてくれたんだけど」（〇〇で働く姉／薬剤師の親友）
- B：意外な豆知識 or お役立ち情報を提示（「実は〇〇なんだって」「〇〇の出番だよ」）
- 切断：「〜って聞いたら、」「〜するんだけど、」で切ってコメントへ
- コメント欄：D 詳細・体験談 ＋ F さりげない商品リンク（「ついでに」「広まって欲しい」トーン）

**自分のネタで作るには**
自分の身近に「その道の人（職業・勤務先を持つ知人）」を設定し、「〇〇が教えてくれたんだけど」から入る。中身は、みんなが知らない意外な内情か、困りごとを解決するお役立ち情報にする。本文は「〜って聞いたら」「〜するんだけど」で切り、詳細と体験談はコメント欄へ。商品は最後に「ついでに」「広まって欲しい」の善意トーンで添える。

## 14. 呼びかけ命令型

> 「〇〇たち！！」と属性を名指しで呼びかけ、続けて「〇〇しろ！！」と乱暴なタメ口の命令で**結論を先に言い切る**。そのあとメリットだけを畳みかける。「フック → 結論 → メリット」の順番が固定なので、読み手が一切迷わない。
>
> ※ ノウハウ連打型（9）も呼びかけから入るが、あちらは「教える」トーン。こちらは同じ属性の仲間として「命令する」トーン。

**構造の骨格（この順番を崩さない）**
```
① 属性呼びかけ  ：誰に向けた話かを名指しする
② 命令で結論    ：何をすればいいかを1文で言い切る（商品名・行動をここに置く）
③ メリット      ：時間軸 or 逆説で畳みかける
④ 切る or 言い切る：「何がすごいかというと、」で切る／言い切ってコメントへ
```

**冒頭の呼びかけバリエーション**
「ワーキングママたち！！」「保育園ママたち！！！」「イヤイヤ期のパパママよ！！」「育休ラスト1ヶ月のママたち！！」「0歳児を育ててるひとたち！！！」
- 属性は「悩み＋状況＋立場」で細かくするほど刺さる
- 「おい、」「なぁ、」を頭に足すと圧が増す
- 「！」は3〜4個。丁寧語にした瞬間この型は死ぬ

**本文の例（バリエーションA：時間軸メリット＋切ってコメントへ）**
```
[悩み系属性]たち！！！！
騙されたと思って『〇〇』を使え！！！！
1週間で〇〇が、2週間で〇〇が、3週間で〇〇が変わる。何がすごいかというと、
```

コメント欄1：理由を権威比較で回収 ＋ 使用感の補足
コメント欄2：「これね👇」＋ 商品リンク（PR表記）

**本文の例（バリエーションB：命令＋本文完結・一言コメント）**
```
ママたち！！〇〇を毎日やるんや！！
1週間経てば〇〇が消え去り、1ヶ月で〇〇になって、3ヶ月後には「〇〇？」って思うようになるからよ！！！
```

コメント欄：役割を一言でまとめる ＋ 商品リンク（PR表記）

**本文の例（バリエーションC：逆説メリット）**
```
おい、育児疲れのワーキングママたち！！！
〇〇を使うんだぞ。クソ楽なのにちゃんと効く、意味わかんないでしょ。
```

コメント欄：ダメ押しの一言 ＋ 商品リンク（PR表記）

**ブロック構造**
- A：属性呼びかけ（「〇〇たち！！」）で対象を名指しし、自分ごと化させる
- B：命令で結論を先出し（「〇〇を使え！！」「〇〇やるんや！！」「〇〇するんだぞ」）
- D：メリットを畳みかける。**時間軸型**（1週間→2週間→3週間）か**逆説型**（〇〇なのに〇〇）のどちらかで統一
- F：「何がすごいかというと、」で切ってコメントへ／または言い切って締め、コメント欄に一言＋リンク

**穴埋めテンプレート**
```
[悩み]＋[状況・立場]たち！！！！
[命令で結論：〇〇を使え／やるんや／するんだぞ]！！！！
[メリット①（1週間で〇〇）]、[メリット②（2週間で〇〇）]、[メリット③（3週間で〇〇）]。何がすごいかというと、
```

**自分のネタで作るには**
1. 呼びかける属性を決める（「悩み＋状況・立場」で細かくするほど刺さる）
2. 命令1文で結論を言い切る（ここに商品名・行動を置く。この時点では理由を一切説明しない）
3. メリットは時間軸か逆説のどちらかで統一
4. 口調を最後まで崩さない（途中で丁寧語に戻ると型が壊れる）
5. 商品リンクは必ずコメント欄（本文には貼らない）

補足：「〇〇が治る」「必ず痩せる」など身体・美容効果の断定は禁止。「〇〇になった気がする」「〇〇って思うようになる」のように体感・主観トーンへ寄せる。
