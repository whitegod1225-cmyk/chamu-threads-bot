## @hoiku_nemui（保育士アカウント）

**分析日**：2026-07-24  
**参照投稿**：2026/07/15〜16 の計4テーマ  
**特徴**：子育て関連で高閲覧数を記録しているスレッド型投稿

---

### 投稿構造の骨格

```
1枚目：現場の具体的場面（いつ・誰が・何をした）
        ↓「動詞＋読点」で切る（「こう言ったんよ、」「試してみたら、」）
2枚目：反転・結果・理由
        ↓ 専門家・ベテランの言葉として提示
3枚目〜：補足 or CTA（「〇〇してる人、これをやってみて」）
```

---

### 取り込む技法（3つ）

#### ①「現場目撃→反転」フック
- 普通の反応（読者が予想する行動）を先に置いてから、逆の行動・結果を見せる
- 映像が浮かぶ具体性が重要（年齢・場面・秒数まで書く）

**ちゃむ。転用例**：
```
1歳の子がぐずり始めて、とっさに抱っこしようとしたら
助産師さんが「ちょっと待って」って言ったんよね。
```

#### ②「動詞＋読点」で1枚目を終わらせる
- 「試してみたら、」「言ったんよ、」「こう言われて、」
- 結果・答えを出さず**余韻で続きを読ませる**

**使える終わり方のストック**：
- `〜してみたら、`
- `先生はこう言ったんよ、`
- `2週間後に気づいたんよね、`
- `聞いてみたら返ってきた言葉が、`

#### ③ 権威の借用（専門家・ベテランに語らせる）
- 自分の主張ではなく「保健師に言われた」「ベテランの先生がやった」として提示
- 読者の反発が下がり、情報として受け取ってもらいやすい

**ちゃむ。転用例**：
```
助産師さんに聞いたら「それが逆効果の場合があるんよ」って。
（理由を続けて書く）
```

---

### 取り込まない要素

| 要素 | 理由 |
|------|------|
| 「んよ」「んよね」語尾の多用 | ちゃむ。の語尾と被る・借用に見える |
| 7枚超のスレッド | ちゃむ。の強みは短く刺さる構造。長尺化は差別化を失う |
| 仕事系コンテンツ（転職・職場） | ちゃむ。のターゲットはパパママ読者。保育士向けではない |

---

### テンプレ（ちゃむ。版「現場目撃逆張り型」）

```
【1枚目フック】
〇歳の子が〜して、とっさに〜しようとしたら
〇〇（専門家・ベテラン）が「待って」って言ったんよね。

【2枚目 反転＋理由】
その子が自分で〜できた。〜秒待っただけで。

「すぐ入ると子どもは〇〇の機会をなくすんよ」
（専門家・ベテランの言葉として提示）

【3枚目 CTA】
〇〇してるお母さん・お父さん、
まず〇〇だけやってみて。
```

### 追記分析（2026-08-08）：3連否定→概念再定義型

**参照投稿**：[DbnfibKHyRE](https://www.threads.com/@yu_home100/post/DbnfibKHyRE)（表示150,000）

#### ④「3連否定」でクリフハンガーを作る

読者が「これだろう」と思う答えを3つ連続で否定してから「共通しているのは...」で切る。
3つ否定することで「この人は普通の答えを言わない」という信頼が積み上がり、続きへの欲求が強くなる。

**ちゃむ。転用例**：
```
怒りっぽい子は、
叱られすぎてるわけでもなく
わがままなわけでもなく
育て方が間違ってるわけでもない。
共通してるのは、
```

#### ⑤「概念再定義の1行」でリストを束ねる

具体的なリスト（5点）を並べた後に、それを1つの新しい言葉で束ねる。
例：「友だちを作る力」→「友だちとの関係を続ける力」

この1行が記事全体の「核心」になり、読者が「そういうことか」と腑に落ちる瞬間を作る。
**note記事の購買動機はここで生まれる**（リストではなく、その束ね方を買う）。

**ちゃむ。転用例**：
```
・泣いてもすぐ立ち直る
・新しい場所でもなじめる
・友だちとぶつかっても関係を続けられる

要するに、「強い子」じゃなくて
「ゆらいでも戻ってこられる子」です。
```

#### ⑥「読者の不安ワードを直接引用して誘導する」3枚目パターン

3枚目でnoteURLを置くとき、URLだけ or 「詳しくはnoteで」ではなく
**読者が心の中で思っている不安の言葉をそのまま引用してから誘導する**。

例：「うちの子小学校で大丈夫かな…と不安なママへ。その不安、家での関わりで変わるかもしれません。」

→ 読者が「私のことを言ってる」と感じてリンクを踏む確率が上がる。
→ noteのターゲット絞り込みにもなっている（不安なママだけに呼びかける）。

**ちゃむ。転用例**：
```
「夜泣きでもう限界かも…」と感じてるママへ。
その夜が、少し楽になるかもしれない話を書きました。
[noteURL]
```

#### ⑦「コメント質問返し」でコメント数を増やす

読者コメントに「いいですね！」と返すのではなく、
「〇〇をどんなふうにやっていたか教えてもらえますか？」と**質問返し**をする。
→ 読者が詳細を語り出し、コメント数・スレッドの深さが増す。
→ 投稿へのアルゴリズム評価が上がる可能性がある。

ちゃむ。への転用：返信するとき「〇〇の場面、もう少し聞かせてもらえる？」「どの言葉が特に刺さった？」など
具体的な質問で返す。
