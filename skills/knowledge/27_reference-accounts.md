---

### 投稿構造の骨格

```
1枚目：現場の具体的場面（いつ・誰が・何をした）
        ↓「動詞＋読点」で切る（「こう言ったんよ、」「試してみたら、」）
2枚目：反転・結果・理由
        ↓ 専門家・ベテランの言葉として提示
3枚目〜：補足 or CTA（「〇〇してる人、これをやってみて」）
```

---

### 取り込む技法（3つ）

#### ①「現場目撃→反転」フック
- 普通の反応（読者が予想する行動）を先に置いてから、逆の行動・結果を見せる
- 映像が浮かぶ具体性が重要（年齢・場面・秒数まで書く）

**ちゃむ。転用例**：
```
1歳の子がぐずり始めて、とっさに抱っこしようとしたら
助産師さんが「ちょっと待って」って言ったんよね。
```

#### ②「動詞＋読点」で1枚目を終わらせる
- 「試してみたら、」「言ったんよ、」「こう言われて、」
- 結果・答えを出さず**余韻で続きを読ませる**

**使える終わり方のストック**：
- `〜してみたら、`
- `先生はこう言ったんよ、`
- `2週間後に気づいたんよね、`
- `聞いてみたら返ってきた言葉が、`

#### ③ 権威の借用（専門家・ベテランに語らせる）
- 自分の主張ではなく「保健師に言われた」「ベテランの先生がやった」として提示
- 読者の反発が下がり、情報として受け取ってもらいやすい

**ちゃむ。転用例**：
```
助産師さんに聞いたら「それが逆効果の場合があるんよ」って。
（理由を続けて書く）
```

---

### 取り込まない要素

| 要素 | 理由 |
|------|------|
| 「んよ」「んよね」語尾の多用 | ちゃむ。の語尾と被る・借用に見える |
| 7枚超のスレッド | ちゃむ。の強みは短く刺さる構造。長尺化は差別化を失う |
| 仕事系コンテンツ（転職・職場） | ちゃむ。のターゲットはパパママ読者。保育士向けではない |

---

### テンプレ（ちゃむ。版「現場目撃逆張り型」）

```
【1枚目フック】
〇歳の子が〜して、とっさに〜しようとしたら
〇〇（専門家・ベテラン）が「待って」って言ったんよね。

【2枚目 反転＋理由】
その子が自分で〜できた。〜秒待っただけで。

「すぐ入ると子どもは〇〇の機会をなくすんよ」
（専門家・ベテランの言葉として提示）

【3枚目 CTA】
〇〇してるお母さん・お父さん、
まず〇〇だけやってみて。
```

### Threads投稿の骨格（3枚note誘導型）

```
1枚目：「N年間見てきて思うことがある」→ 逆張りで予想を外す → 「…」で切る
2枚目：箇条書きリストを全公開 → 「そんな子の親が〜やっていることがあった☺️」で引く
3枚目：noteURLのみ
```

→ **型Y-1**として `15_post-structures_normal.md` に定義済み

---

### note記事の骨格（有料向け）

| セクション | 役割 | ちゃむ。への転用 |
|-----------|------|--------------|
| 冒頭疑問文2行 | 読者の不安を代弁 | 「〜かな？」「〜どうしよう…」で始める |
| 現場観察描写 | 権威付け＋具体性 | 「毎年そう感じる子がいる」「11年間見てきた」 |
| 逆のケース | 共感強化 | 「優しい子なのに、なぜか…」 |
| **命題1行** | 核心の断言 | 「〇〇の土台は家庭での何気ない関わりの中で育っている🌱」 |
| このnoteはこんな方に | ターゲット絞り込み | 悩み6〜8個を箇条書き→「一つでも当てはまるなら」 |
| **Not what先出し** | 反発防止・信頼構築 | 「〇〇を書いたものではありません」を先に言う |
| 得られること | アウトカム可視化 | 読後の変化を3つ以上・具体的に書く |
| **なぜこの価格か** | 購入障壁除去 | 「無料にない情報＝保育士しか知らない内側の視点」 |
| はじめに締め | 親近感 | 「完璧な親になるためではない。私も失敗した」 |

→ `note-article-seller.md` の有料note構成に反映済み
