# 冒頭フック運用ガイド｜画像勝負タイプ（生成用）

> このファイルは**楽天商品スクショから投稿を作るときの「1行目（本文冒頭）」を生成するためのファイル**。
> 文章勝負タイプの `kapi-first-lines.md` とは**役割が逆**なので混ぜない（下の対比表を必ず読む）。
> 型の全体像・コメント欄の作り方は `/affiliate-writer` スキルで処理する。このファイルはその「本文1行目」だけを高速に選ぶための索引。

---

## ⚠ 文章勝負タイプとの決定的な違い

| | 文章勝負（kapi-first-lines.md） | 画像勝負（このファイル） |
|---|---|---|
| 価値を伝えるのは | **本文（言葉）** | **画像（商品そのもの）** |
| フックの仕事 | 価値の入口をつくる | **タップさせることだけ** |
| 商品説明は | フックで匂わせる | **本文に書かない（画像が説明する）** |
| 主な武器 | 権威性・ターゲット指定・恐怖 | **ネガティブ予感・目撃談・固有名詞** |
| 名詞の使い方 | 肩書き（元保育士） | **大手企業名・ブランド名**（コストコ／無印／adidas） |
| リンク・値段 | 本文に無し | **本文に無し（全部コメント欄）** |

**画像勝負の鉄則：本文の1行目は「この後マイナスなことを言いそう」と思わせて、言い切らずに切る。** タイムラインではコメント欄が隠れているので、本文の唯一の仕事はタップを取ること。

## 0. AIへの実行手順

商品スクショを受け取ったら、必ずこの順で1行目を作る。

1. **商品タイプを判定**する（色柄バリエ豊富／人が使う場面が浮かぶ／セール表示あり／有名ブランド新作）
2. 「§4 商品タイプ別 優先フック」から**主軸のフック群を1つ**選ぶ
3. 「§5 重ね方」で**大手企業名 or 固有名詞**を必ず1つ乗せる（アルゴリズム加速）
4. §2 のテンプレの〇〇を、**スクショから読み取った具体名詞**で埋める（店名・シーンは補完してよい）
5. **フックの直後を「、、、」「...」で切る**（§3）。言い切らない
6. **§6 の禁止チェック**を全項目通す。1つでも該当したら作り直す

### 絶対原則

- **商品名・値段・リンクを本文に書かない。** 画像が説明する。書いた瞬間に広告化してスクロールされる。
- **マイナスは「予感」だけ。本文で悪口を言い切らない。** 反転はコメント欄でやる。
- **大手企業名かブランド名を必ず1つ入れる。** 実話性とアルゴリズム露出を同時に稼ぐ。
- **1行目は40字以内。** 長いと画像が小さくなり、この型の強みが消える。

## 1. フックの構造式

画像勝負のフックは、ほぼ全部この3要素の組み合わせでできている。

| 要素 | 役割 | 例 |
|---|---|---|
| **①タップ動機（引き）** | この後マイナスを言いそう→確かめたい | ごめん、／こういうママって...／だって、 |
| **②固有名詞** | 実話性＋アルゴリズム配信 | コストコ／無印／セリア／adidas／ビルケン |
| **③言いよどみ** | ここで切ると気になる | 、、、／...／..（句点で終えない） |

**最強パターン＝①＋②＋③を1〜2行に詰める**

> 例：`ごめん、ユニクロの〇〇できるなら教えといてよ...／だってこれさぁ、、、`（②ブランド＋①逆ギレ引き＋③言いよどみ）
> 例：`この前コストコで、ふんわりスカート履いてる可愛いママがいて...／こういうママって...`（②コストコ＋①判定保留）

## 2. 型カタログ（全6グループ）

### I1. ネガティブ予感 ─ マイナスを言いそうで＋を言う（最強・主軸）

| 型 | テンプレ | 使いどころ |
|---|---|---|
| 謝罪フック | `ごめん、〇〇は好きなんだけどさぁ、、、` | 画で見せる単品。1〜2行で最小 |
| 謝罪独立行 | `ごめんなさい。／可愛い〇〇なのは認めるんだけど、、、` | 懸念のある商品（派手・クセ強） |
| ブランド謝罪 | `ごめんなさい、〇〇さん。／これ、どう見ても、、` | 定番ブランドの類似・上位互換 |
| 逆接フック | `〇〇も可愛かったんだけど、／こういうママって...` | 目撃したシーンがある服・小物 |
| 判定保留 | `この格好はさすがに／こういう場では、` | ダメ出しに見せて実は称賛 |
| 発言権主張 | `〇〇好きの私から言わせると...` | 専門家目線ダメ出し→実は絶賛 |
| 過去回想 | `学生の時から思ってたんだけど..` | 遭遇した知人の着こなし |
| 自己否定投影 | `私なら選ばなかったなって思ってしまった...` | 「買っておけば」系の後悔で推す |
| 教えといてよ | `〇〇できるなら教えといてよ.../だってこれさぁ、、、` | ブランドへの逆ギレ風＝最上級の褒め |

### I2. 目撃談 ─ 他人が使ってた（押し売り感を消す）

| 型 | テンプレ | 使いどころ |
|---|---|---|
| 店＋人物 | `この前〇〇で、△△してる□□がいて...` | 服・靴・バッグ・育児グッズ全般 |
| 遭遇 | `久々に会った〇〇と△△へ／全身お洒落だったけど、` | 知人の着こなしから紹介 |
| 場面マナー | `〇〇で△△してるママさんがいて。／こういう場では、` | 育児グッズ（実は便利発見） |

> **目撃談は必ず①の引きとセットで切る。** シーンだけ書いて引かないと本文で完結して伸びない。

### I3. 答えを隠す ─ 定番を否定して伏せる（セール・お得の主軸）

| 型 | テンプレ | 使いどころ |
|---|---|---|
| 連呼否定（店ずらし） | `〇〇は、△△で買いません。／□□でも買いません。` | 商品1つをセールで売る |
| 連呼否定（商品ずらし） | `△△、〇〇で買いません。／××も、〇〇で買いません。` | 買い方の提案 |
| 理由フリ | `だって、／なぜなら、、` | 連呼の締め。**答えは書かない** |
| 犯人名指し＋再フリ | `〇〇のせいです。だって、` | ブランド名は出すが理由は伏せる |
| ご報告 | `【ご報告】` | 連呼の前置きで身構えさせる |

> **本命ブランド名で終わらない。** 「だって、〇〇が」で切ると答えが割れてタップが消える。

### I4. 固有名詞＋感嘆 ─ ブランド速報（補助・伸びは弱い）

| 型 | テンプレ | 使いどころ |
|---|---|---|
| ブランド直球 | `〇〇あかん...可愛すぎるって...` | 有名ブランドの新作・新色 |
| ぼやき付き | `〇〇...可愛すぎる/△△なのに......` | ↑に「買えない事情」を足す（推奨） |
| ブランド連呼 | `え、ちょっと〇〇の△△に〇〇の本気感じるわ...` | ブランド名を2回で密度UP |
| コラボ断定 | `〇〇天才かよ。これは△△コラボ史上最高やろ...` | 有名ブランド×有名IP |
| 【吉報】新色速報 | `【吉報】〇〇の△△別注の新色やばぁぁぁ‼️/天才的な可愛いさで5度見したわぁぁ‼️` | 有名ブランドの新色/別注を最速速報 |

> **この群は主軸にしない。** 引きが無いぶん伸びが落ちる。必ずぼやき（〜なのに......）を足す。

### I5. 後悔・警告フック ─ おすすめに見せない（最強・逆説）

実測21万〜35万。**ネガティブ予感の最上位。**

| 型 | テンプレ | 実例 |
|---|---|---|
| 警告 | `〇〇、マジで買わないほうがいい。なぜなら、` | モンベルのウイックロンT、マジで買わないほうがいい。なぜなら、（21万） |
| 後悔告白 | `まっっっじで後悔してる！！△△やっと買ったのに…` | バズってるmont-bellのTシャツ、やっと買ったのに…（35万） |
| 失敗風 | `調子に乗って買って失敗したんだけど‼️/だってさ` | 〇〇のパンツ、調子に乗って買って失敗したんだけど‼️（25万） |
| 誤認 | `正直、ちょっと〇〇かと思ってたら、、、` | オシャレなキーチャームかと思ったら、、、（1.3万） |

> **効く仕組み**：「買わないほうがいい」「後悔」は否定100%なので確実に足が止まる。コメント欄で「良すぎるから沼る＝実質最大級の推薦」に反転させる。**本文で本当の欠点を書かない**のは他の型と同じ。

### I6. 意外な事実・トリビア ─ 知ってた？で止める

実測6万〜10万。

| 型 | テンプレ | 実例 |
|---|---|---|
| デザイナー系 | `〇〇のデザイナーが△△をデザインしてるって知ってた？` | エルメスのデザイナーがトリーバーチを…（6.4万） |
| 元デザイナー暴露 | `最近〇〇いいなと思ったら、△△の元デザイナーじゃん！` | coachがボッテガ、ヴィトンの元デザイナーじゃん（10万） |
| 系列暴露 | `〇〇の姉妹ブランド、質いいのに手が届く価格なんて....` | eteの姉妹ブランド、質は良いのに…（6.8万） |

> **固有名詞を2つ重ねる**ほど強い（両ブランドの検索層に乗る）。

## 3. フックの後をどこで切るか

**画像勝負は「言いよどみ」で切るのが基本。** 句点で言い切ると完結してタップされない。

| 切り方 | 例 |
|---|---|
| 「、、、」で言いよどむ | `好きなんだけどさぁ、、、` `だってこれさぁ、、、` |
| 「...」で余韻 | `こういうママって...` `可愛すぎるって...` |
| 「、」で止める | `さすがにごめん、` `だって、` `〇〇のせいです。だって、` |
| 「..」で息を飲む | `仕事帰りらしいんだけど..` `ほんとすみません、` |
| 答えを出さない | `なぜなら、、`（どこで買うかを言わない） |

**NG：** マイナスを本文で言い切る／商品名や値段まで書く／「〜で最高でした。」と結論を出す。

## 4. 商品タイプ別 優先フック

スクショの見た目で主軸を決める。迷ったら **I1（ネガティブ予感）**。

| 商品タイプ | 主軸（第1候補） | 重ねる | 具体 |
|---|---|---|---|
| **色柄バリエが多い／形が特徴的** | I1 謝罪フック（ごめん型） | 選べない反転／固有名詞 | マグ・カーテン・雑貨の色展開 |
| **服・育児グッズ（人が使う場面が浮かぶ）** | I2 目撃談＋I1 引き | 大手企業名／自分の失敗談 | コストコ・イオン・アウトレット |
| **スクショにセール・クーポン表示** | I3 連呼否定 | 大手企業名を2〜3店／割引率 | ユニクロ・しまむら・LOFT |
| **有名ブランドの新作・コラボ** | I4 固有名詞＋感嘆 | ぼやき（〜なのに）／コラボ先 | adidas・ビルケン・LOWRYS×IP |

| **有名ブランドの意外な繋がり** | I6 意外な事実 | 固有名詞2つ | 元デザイナー／姉妹ブランド |

## 5. 重ね方ルール

画像勝負では **引き（①）× 固有名詞（②）** の2要素が土台。これに③言いよどみを足して完成。

### 鉄板の組み合わせ

| 組み合わせ | 完成形 |
|---|---|
| 大手企業名 × 目撃談 × 判定保留 | `この前コストコで、〜なママがいて...／こういうママって...` |
| ブランド × 逆ギレ × 言いよどみ | `ごめん、ユニクロの〇〇できるなら教えといてよ.../だってこれさぁ、、、` |
| ご報告 × 連呼否定 × 理由フリ | `【ご報告】夏の服は、ユニクロで買いません。...／だって、` |
| 謝罪 × 譲歩 × 言いよどみ | `ごめん、絵本モチーフは好きなんだけどさぁ、、、` |
| ブランド × 感嘆 × ぼやき | `ビルケンあかん...可愛すぎる／靴箱置くとこないのに......` |
| ブランド謝罪 × 二度見 | `ごめんなさい、無印さん。／どう見ても、、` |

### 重ねる上限

**引き＋固有名詞＋言いよどみの3要素まで。** それ以上は本文が長くなり画像が小さくなる。**1行目は40字以内。**

### 大手企業名リスト（②に使う）

コストコ／無印／イオン／セリア／ダイソー／ニトリ／ユニクロ／GU／しまむら／西松屋／バースデイ／LOFT／PLAZA／アウトレット／業務スーパー／シャトレーゼ

## 6. 禁止チェックリスト（生成後に必ず全項目確認）

- ☐ **商品名を本文に書いていないか** ─ 画像が説明する。書くと広告化
- ☐ **値段・リンク・pr表記を本文に書いていないか** ─ 全部コメント欄
- ☐ **言い切って完結していないか** ─ 「、、、」「...」で切れているか
- ☐ **マイナスを本文で言い切っていないか** ─ 予感だけ。反転はコメント欄
- ☐ **大手企業名 or ブランド名が入っているか** ─ ②が無いと露出が伸びない
- ☐ **本命ブランド名で終わっていないか**（連呼型） ─ 答えが割れる
- ☐ **シーンを書いたのに引きが無い状態でないか** ─ 目撃談は必ず①で切る
- ☐ **1行目が40字以内か** ─ 長いと画像が小さくなる
- ☐ **1メッセージに絞れているか** ─ 2つ言おうとしていないか

## 8. フックの実績優先度（迷ったらこの順）

3. **衝動買い×コスパ驚き**（ハイブランドなのにこの使いやすさ何事…？） ─ 59万
4. **後悔・警告フック（I5）**（買わないほうがいい／後悔してる） ─ 21万〜35万
5. **情報格差**（これ、絶対に知っといて。） ─ 34万
6. **謝罪 × 発言権主張**（サンリオ好きの私から言わせると…） ─ 25万

9. **固有名詞＋感嘆のみ**（さすが〇〇可愛すぎた...） ─ 6千〜（引きが無いと最下位）

### アーカイブから読み取れる傾向（メモ）

- **50万超はほぼ全部ネガティブ予感系**（目撃談73万・ごめん66万・後悔35万）。褒めから入る投稿は上限が低い。
