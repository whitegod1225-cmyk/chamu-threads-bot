# Threads投稿ライティングルール

> **用途**: Threads投稿を生成するとき、必ず最初に参照するルール集。 **適用範囲**: 本文・コメント欄の両方。すべての投稿に適用する。 **優先順位**: 「1. 絶対ルール」＞「2. 投稿の基本構造」＞「3〜7の作り方ルール」。 迷った場合は、上位のルールを優先する。

---

## 0. AIへの実行手順

投稿を生成するときは、必ず次の順番で判断する。

1. **投稿タイプを判定する** → 文章で勝負する投稿か、画像で勝負する投稿か（→ 2-4）
2. **文字数の型を決める** → ショート / ミドル / ロング（→ 2-2）
3. **1行目を作る** → 3要素のどれかを必ず入れる（→ 3）
4. **本文を作る** → 具体性・固有名詞・行動指示を入れる（→ 4）
5. **コメント誘導で止める** → 一番知りたい情報の直前で切る（→ 5）
6. **コメント欄を書く** → 本文の続きとして詳しく説明する（→ 2-3）
7. **表現を整える** → テンポ・表記バランス・感情表現（→ 6）
8. **チェックリストで検算する** → 1つでも引っかかったら書き直す（→ 8）

## 1. 絶対ルール（ルール違反したら非採用）

### 1-1. 禁止事項

以下は例外なく禁止。1つでも含まれていたら、その投稿は破棄して作り直す。

**［内容の禁止］**

- 暴力的な発言・差別・誹謗中傷・違法行為を促す内容
- 「絶対儲かる」といった断定的な金銭保証の表現
- 他アカウントの投稿をそのまま流用すること

**［表記の禁止］**

- 本文中へのURLリンク掲載
- ＃（ハッシュタグ）の使用
- 「：」（コロン）の使用
- 「""」（ダブルクォーテーション）の使用
- 「＊」（アスタリスク）の使用

**［根拠のない数字の禁止］**

- ドメイン知識ファイルに裏付けのない数字は書かない
    - NG例：「9割の人が肌質改善を実感」「継続率95%」
    - 価格・統計・割合は、必ず事前リサーチかドメイン知識からの引用に限る

**［エンゲージメントベイトの禁止｜アカウントBANの対象］**

- 「いいね○○超えたら〜」「いいね○○件で公開」
- 「フォローしたら〜教えます」「リプくれたら〜」
- いいね・フォロー・リプ・保存などの行動を条件にコンテンツを出し渋る表現は全てNG
- 「知りたい人いる？」「気になる人いる？」は需要チェックとしては問題ない。ただし「○○したら教える」との組み合わせはNG

**［他人投稿の個人署名の流用禁止］**

- 他人の実投稿を作り替えるとき、次はそのまま残さない（残ったら即ボツ）。詳細と考え方は 7-4 参照
    - 元投稿の@ハンドル・アカウント名・発信テーマの宣言
    - 発信者本人の生活・家庭・購入の具体エピソード
    - 締めのCTA・決まり文句・特徴的な言い回し

### 1-2. AIが絶対にやってはいけない表現

AIが投稿を生成する時に最も陥りやすいミス集。ここに書いてあるパターンを1つでも使ったら即ボツ。

#### ① 「それ○○」構文を使うな

「それ」で受けて断定する構文。AIが多用するパターンで不自然。

```
NG: 「それ広告に踊らされてるだけだから」
NG: 「それ手術の結果じゃなくてメイクの結果だから」
NG: 「それ医療じゃないから」
```

**代わりにどう書くか:** 「それ」を消して直接言い切る、または主語を変える。

```
OK: 「広告に踊らされてるだけだから」
OK: 「手術の結果じゃなくてメイクの結果だから」
OK: 「医療じゃないから」
```

#### ② 「〜じゃなくて」構文を使うな

否定から入って本題を言う構文。くどい。

```
NG: 「プロンプトじゃなくてナレッジ設計で決まる」
NG: 「ツールじゃなくて知識の渡し方が大事」
```

**代わりにどう書くか:** 直接言い切る。

```
OK: 「ナレッジ設計で決まる」
OK: 「知識の渡し方が全て」
```

#### ③ 一文の情報密度を最大化しろ

ダラダラ書かない。一文で伝える情報量を最大にする。冗長な説明・接続・前置きは全カット。

```
NG: 「美容医療が高いと思ってる人がいるかもしれないけど、
      それは大手チェーンの価格しか見てないだけだと思う」
OK: 「美容医療が高いと思ってる人、大手チェーンの価格しか見てないだけ」
```

## 2. 投稿の基本構造と文字数

### 2-1. 投稿構造

```
冒頭1行目＝フック（掴み）
　↓
本文で価値提供
　↓
締める or コメント誘導
```

### 2-2. 文字数｜本文

Threadsの本文は、長さによって以下の3つの型に分けて使い分ける。

#### ① ショート投稿

- 最小：10文字程度
- 最大：60文字
- 理想：40〜60文字
- 行数：1〜3行程度（1行20文字前後）

#### ② ミドル投稿【基本】

- 最小：61文字
- 最大：120文字
- 理想：80〜100文字
- 中央値：約88文字
- 行数：4〜6行程度（1行20文字前後）

基本的には、このミドル投稿を軸にする。 分析した1万ビュー超え投稿では、最も多かったのがこのミドル型。 短すぎず、長すぎず、次の3つを1投稿で作りやすい。

- 興味を引く
- 最低限の情報を与える
- 続きが気になる状態でコメント欄へ送る

#### ③ ロング投稿

- 最小：121文字
- 最大：500文字程度
- 理想：130〜180文字
- 中央値：約145文字
- 行数：7行以上（1行20文字前後）

### 2-3. 文字数｜コメント欄

**本文とコメント欄は役割を分ける。**

- 本文：興味を引いて、コメント欄を見たくさせる場所
- コメント欄：詳しい理由・体験・情報・商品について説明する場所

この役割分担のため、コメント欄は本文より長くてよい。

#### コメント欄の基本文字数

- 最小：100文字程度
- 最大：500文字
- 理想：200〜350文字
- 中央値：約264文字
- 平均：約262文字

#### 長さ別の考え方

**▼ 100〜200文字｜短い補足型** 本文である程度内容を伝えている場合に、以下を補足するときに使う。

- 結論
- 簡単な理由
- 商品紹介

**▼ 200〜350文字｜基本** 最も使いやすい長さ。以下を自然に入れられる。

- 本文の続き
- 理由
- 具体例
- 実体験
- 商品の特徴

迷った場合は、この文字数を基準にする。

**▼ 350〜500文字｜詳しい解説型** 体験談、有益情報、商品の詳しい説明など、情報量が必要な場合に使う。 ただし、無理に1コメントへ詰め込まない。 500文字近くになり、さらに説明が必要な場合は、以下のように分割する。

```
コメント① → コメント② → コメント③
```

**▼ URLがある投稿は必ず2段に分割する（2026-10追加・厳守）**

楽天アフィリエイトURLは長く500文字制限に引っかかりやすい。URLを含む投稿はすべて以下の構成にする。

```
本文（フック・画像ありの場合も可）
　↓
コメント欄1（返信1）：詳しい内容・体験談・ベネフィット（URLなし・500文字以内）
　↓
コメント欄2（返信2）：CTA1行 ＋「Rakuten PR」＋ URL のみ
```

これはかぴ式でURLを貼る場合も同じルール。コメント欄1にURLを混ぜない。

#### 本文とコメント欄の基本イメージ

```
本文：80〜100文字前後
　↓
コメント：200〜350文字前後
```

つまり、

- 本文では全部説明しない
- コメント欄で詳しく説明する

この役割分担を徹底する。

### 2-4. 補足｜ジャンルによって本文の適正文字数は変わる

**ここまでの文字数ルールを、すべてのジャンルに同じように当てはめないこと。** 投稿は大きく分けると、次の2種類がある。

- ① 文章で興味を引く投稿
- ② 商品画像・見た目で興味を引く投稿

**まずこのどちらなのかを判断してから、本文の長さを決める。**

#### ① 文章で興味を引くジャンル

例：

- 育児
- 美容
- 悩み解決系
- 有益情報系

これらは、次の流れを文章で作る必要がある。

```
悩み → 意外な事実 → 理由・体験 → 続きが気になる
```

そのため、ショートだけにこだわらず、以下も積極的に使う。

- ミドル：80〜100文字前後
- ロング：130〜180文字前後

基本はミドル投稿を軸にする。

#### ② 商品画像・見た目で興味を引くジャンル

例：

- ファッション
- インテリア
- 雑貨
- デザイン性の高い商品

これらのジャンルは、文章ではなく商品画像そのものがフックになる。 そのため、本文で商品の魅力をすべて説明する必要はない。 分析したファッション・インテリア・雑貨系8アカウントのいいね上位投稿では、約8割が60文字以下のショート投稿だった。

文字数の目安は以下。

- 基本：60文字以下
- 理想：30〜60文字
- 中央値：約41文字
- 行数：1〜3行（理想は2行前後）

画像を見れば商品の魅力が伝わる場合は、長く説明するのではなく、「画像＋短い一言で欲しくさせる」を優先する。

一言の例：

- 「かわいすぎる」
- 「これ考えた人天才」
- 「女の子産んだら絶対着せたい」
- 「ユニクロさん、これはズルい」
- 「こういうの探してた」

画像の魅力を補強する一言だけでも投稿として成立する。

#### 【重要】判断の結論

- 文章で勝負する投稿 → **ミドル**を基本に考える
- 画像で勝負する投稿 → **ショート**を基本に考える

まず投稿の内容を見て、「文章を読ませて興味を作る投稿なのか」「画像を見せて興味を作る投稿なのか」を判断してから、本文の長さを決める。

## 3. 1行目（フック）の作り方

### 3-1. 大原則

**投稿が伸びるかどうかは、1行目で大きく決まる。**

- 1行目の目的は「内容を説明すること」ではなく「2行目を読ませること」
- 1行目で説明を始めない
- 1行目には、以下の3要素のうち**最低1つを必ず入れる**
- 強い投稿では、複数を組み合わせる

### 3-2. 要素① 有益そう・信頼できそう

「この投稿は見ておいた方がいい。見ないと損する」と思わせる。

**使える要素：**

- 強く断言する
- 禁止する（◯◯はするな）
- 権威性を出す

**例：**

- ◯◯は絶対するな。
- 0歳のうちに◯◯は絶対やれ。
- 現役保育士です。〜
- 10年間ニキビがほぼできてない私が言うけど、

**補足：** 信頼につながるのは資格や職業だけではない。「実際に使った」「何年も経験している」「複数の商品を使い比べた」なども信頼になる。

**この3つの中では「権威性を出す」が最も強い。**

- 「元小児科勤務です〜」
- 「現役看護師です。1億回は言ってます。」
- 「現役保育士で1000人の子供を見てきたけど、」

### 3-3. 要素② 意外性・違和感がある

「え、そうなの？」「普通は逆じゃない？」と思わせて、スクロールする手を止める。

**使える要素：**

- 常識をひっくり返す
- 一般的なイメージと逆のことを言う
- 本音を言う
- タブーに触れる
- 強い言葉を使う

**例：**

- 育休、取らなければよかった。
- ハロワに行って後悔した。
- 正直、これ買う意味なくない？
- 赤ちゃん用って書いてあっても安心するな。

**【必須条件】** 無理に逆張りするのではなく、投稿の続きを読めば納得できる内容にする。

### 3-4. 要素③ 自分ごと化させて、続きを気にならせる

「これ私のことだ」「で、どうなったの？」「何を使ってるの？」と思わせる。

**使える要素：**

- 具体的なターゲットを指定する
- 悩みをそのまま言葉にする
- 具体的な数字を入れる
- 期限・タイミングを入れる
- 結論をあえて全部言わない

**例：**

- 今年初めて夏を迎える0歳ママへ
- 夜泣きでまともに寝れてない人、これ見て。
- ママ友5人に聞いたら全員これ使ってた。
- 美容液10種類使ったけど、結局残ったのはこれだった。
- あと3日でおむつ値上げ！！！

**【ターゲットの絞り方】** ターゲットは具体的にする。ただし絞りすぎない。

- NG（絞りすぎ）：生後7ヶ月で、初めての子どもで、離乳食を始めて2週間のママ → 対象者が少なくなる
- OK（自分ごと化しやすい広さ）：0歳ママ／今年初めて夏を迎えるママ／離乳食に悩んでいるママ

### 3-5. 要素の組み合わせ方

さらに強い投稿では、複数の要素を組み合わせる。

- 「現役保育士です。0歳ママ、これだけは絶対やめて。」 → 有益・信頼 × ターゲット × 強い主張
- 「今年初めて夏を迎える0歳ママへ。赤ちゃん用の日焼け止めだからって安心しないで。」 → ターゲット × 意外性 × 続きが気になる

### 3-6. 伸びない1行目の共通点（これに当てはまったら書き直す）

1行目が次のどれかに当てはまると伸びない。

- **当たり前のことを言っている**（断言していても中身が常識どまり。例：「NISAは絶対やった方がいい！」）
- **1行目が冗長で、本題にたどり着くまでが遠い**
- **読んだ人が「うん、それで？」で終わる**（心が動かず、続きが気にならない）
- **抽象的なことを言っている**（場面が思い浮かばない）

とくに抽象的な内容は、読み手がその場面を頭の中で映像として想像できる形にする。そうしないと、内容が正しくても読み飛ばされる。

|抽象的（NG）|改善例|
|---|---|
|「出産を楽にしたい妊婦さんへ」|「真夏の臨月を泣きながら3回、経験した私が！！毎日やってたこと教える！！！」|
|「手足口病が怖いパパママへ」|「2歳の息子が手足口病。「熱」でも「発疹」でもなく、「水すら飲めなくなった時」がいちばん焦った。」|
|「ワンオペお風呂をラクにしたいママへ。」|「0歳のワンオペお風呂で気づきたかった。ハンドスピナーはお風呂に持ち込むべき。洗ってる間ずっと動き回る赤ちゃん追いかけるより100倍ラク。」|
|「全国のママ〜！！！」|「お風呂上がり、パンツ一丁で逃げる子ども追いかけて、保湿して着替えさせてたら自分の顔カッピカピなママへ。」|

**共通する問題:**

- 「楽にしたい」「怖い」「ラクにしたい」のような呼びかけだけでは、具体的な場面が浮かばない
- 読み手が「あ、これ私だ」と思える瞬間・情景・数字が入っていない
- 対象設定は間違っていないのに、タイムラインで指が止まらない

## 4. 本文の作り方

### 4-1. とにかく具体的に書く

**抽象的な投稿は伸びない。**「固有名詞」「具体的な数字」「具体的な場面」「すぐに真似して行動できること」を入れる。

#### 具体度の5段階（点数が高いほど良い）

```
0点：「育児の出費を減らせ」
→ 当たり前のこと

25点：「おむつはまとめ買いしろ」
→ まだ普通

50点：「おむつはセール日にまとめ買いしろ」
→ 少し具体的

75点：「おむつはセール日に楽天でまとめ買いしろ」
→ かなり具体的

100点：「パンパースは毎月1日の楽天ワンダフルデーでまとめ買いしろ！」
→ 最も具体的
```

**【AIへの指示】75点以上のもので作成。それ以下は却下。**

#### 抽象的から具体的への変え方

| 要素  | 抽象（NG）          | 具体（OK）                                |
| --- | --------------- | ------------------------------------- |
| 数字  | 「すぐ覚えた」         | 「3日で動物100匹覚えた」「1週間で100国の国旗の数おぼえた」 |
| 場所  | 「スーパー」「カフェ」 | 「イオン」「スタバ」                        |
| 商品  | 「ベビーカー」「絵本」 | 「サイベックスのベリル」「しましまぐるぐる」            |
| 期間  | 「最近」「長く」    | 「3日前」「2年間」                        |
| 年齢  | 「赤ちゃん」「こども」 | 「生後3ヶ月」「2歳児」                      |
| 金額  | 「安い」「お得」    | 「980円」「1万円以上損する」                  |
| 頻度  | 「定期的に」          | 「週3回」「毎週土曜日」「毎晩」                      |
| 資格  | 「医療関係者」         | 「小児科看護師」「元保育士」                    |

### 4-2. 固有名詞を出す

**出せる場合は必ず具体名まで出す。**「このバッグかわいい」ではなく「GUのこのバッグかわいい」。

### 4-3. ピンポイントの悩みを狙う

ぼんやりしたテーマではなく、「まさにこれ」と名前がつけられるくらい具体的な悩みに絞る。

|広すぎ（NG）|ピンポイントな悩み（OK）|
|---|---|
|家事がラクになる方法|離乳食の作り置き / 寝かしつけの時短 / イヤイヤ期の乗り切り方|
|プレママに寄り添う発信|産後の入院準備 / 陣痛タクシーの呼び方|
|ワンオペ育児のヒント|沐浴の時短動線|

### 4-4. 難しい言葉は、わかりやすく言い換える

機能・仕組みの説明で終わらせず、「その結果、読者に何が起こるか」まで書く。

|難しい・伝わりにくい（NG）|わかりやすい（OK）|
|---|---|
|「速乾性が高い」|「夜洗っても朝には乾いてる」|
|「収納力が高い」|「おむつ5枚・おしりふき・着替えまで全部入る」|
|「軽量設計」|「子どもを抱っこしながら片手で持てる」|
|「撥水加工」|「公園で泥がついてもサッと拭ける」|

### 4-5. 読者がすぐに行動に移せる内容にする

読者が「明日からやろう」と思える具体的なアクションを書く。

### 4-6. 1投稿1テーマに絞る

投稿で伝える主題は1つにする。複数の商品や方法を紹介してもOK。ただし、すべてが**同じ悩み・目的**に向かっていること。

## 5. コメント欄を「見ないと損する」と思わせる

### 5-1. 前提

Threadsは「投稿タップ（コメント欄を読む行動）」と「プロフィールへのアクセス」で伸びる。本文はコメント欄を読ませるためのフック。

### 5-2. 誘導の基本ルール

- 答え・理由・注意点・方法など、**読者が一番知りたい情報の直前で本文を止める**
- 本文とコメント欄を別々の文章にせず、**1本の文章がそのままコメント欄まで続いている感覚**で書く

### 5-3. 良いパターン（読者が「知りたい」と思う）

- 「理由は、」→ なぜなのか知りたくなる
- 「根拠があって、」→ 根拠を確認したくなる
- 「1つだけ注意点があって、」→ 失敗したくないから確認したくなる
- 「1番怖いのが、」→ 何が怖いのか知りたくなる
- 「選び方間違えたら意味なくて、」→ 正しい選び方を知りたくなる

### 5-4. NGパターン

- 「続きはコメント欄へ」
- 「詳細はコメント欄に書きます」
- 「コメント欄見てね」
- 「気になる人はコメント欄へ」

### 5-5. コメント欄の書き方（本文の続きとして書く）

**① 本文の切れ目を、そのまま受けて続ける**
本文とコメント欄を別々の文章にしない。本文の最後（「、」の続き）を、1本の文章としてコメント欄の1行目に書く。

**② 本文が「結果」を匂わせて切ったら、コメント欄はまず結果から書く**
商品名・リンクは、結果や体験を語ってから最後に出す。

**GOOD / BAD例（本文が「半信半疑で飲ませてみたら、」で切れている場合）**

BAD（約束した結果を飛ばして商品名から入っている）
```
次の日には少しずつ口にしてくれて、ほっとした。それがこれ↓ 〇〇シロップ。
```

GOOD（本文の続きとして結果から入り、商品は最後に置く）
```
次の日には少しずつ口にしてくれて、あの時は本当にほっとした。それがこれ↓ 〇〇シロップ。もともとは口内炎用のビタミン剤なんだけど、うちはこれに助けられた。
```

## 6. 文章表現のテクニック

### 6-1. テンポ感

**① 読点「、」で自然な呼吸を作る**
**② 長い一文は「。」で切る**
**③ カギカッコで重要なワードを強調**
**④ 話が変わるところでは自然な接続表現を使う**（でも、けど、だから、ただ、で）
**⑤ 書き言葉ではなく、普段しゃべる言葉で書く**

使える口語：めっちゃ / マジで / え、待って / いや、/ ごめん、/ これさ、/ 〜なんだけど / 〜じゃん

### 6-2. 感情を文字にして出す

「おすすめです」「便利です」と綺麗にまとめず、感じた驚き・後悔・焦り・怒りをそのまま言葉にする。

使える感情表現：こわいこわい。/ やばいやばいやばい。/ マジで後悔してる。/ キレてます。/ ごめん。/ 白目むいてた

### 6-3. ひらがな・漢字・カタカナのバランスを整える

- 漢字にした方が一瞬で意味が伝わる言葉は漢字にする
- 漢字にすると硬くなる言葉はひらがなにする
- 数字で書いた方が見やすいものは数字にする（「三日」→「3日」）
- 同じ意味の冗長表現は削る

## 7. 参考投稿の使い方

### 7-1〜7-3. 構造を抜き出して使う

参考投稿から真似るのはフレーズではなく「読者を動かした仕組み（構造）」。

抜き出すべき核：
- 権威性で信頼させる
- 常識を否定して違和感を作る
- 悩みを具体化して自分ごと化させる
- 候補を否定して答えを焦らす
- 答えの直前で止めてコメント欄を開かせる

### 7-4. 他人のライブ投稿を別の型に作り替えるときの線引き（パクリ回避）

投稿を3レイヤーに分解して扱いを変える。

- **①知識・事実（残してよい）**：一般知識。所有者はいない
- **②構造・型（作り替える対象）**：フックの作り方・切り方・畳みかけ方
- **③個人署名（必ず変える or 消す）**：@ハンドル・アカウント名・発信テーマの宣言・個人エピソード・CTA・言い回し

**③を変えるときの鉄則：** 単語だけ差し替えない。文の型ごと変える。
