# failure-patterns.md ── 既知の障害・失敗パターン

> 障害が発生したら必ずここに記録する。
> `/conductor-check` はこのファイルを参照し、再発の兆候を検出する。
> 記録フォーマット：症状 → 原因 → 修正内容 → 予防策

---

## FP-001：コメント欄に次の投稿のメタデータが混入

**発生時期**：2026-07  
**症状**：投稿のコメント欄（セルフリプライ）に、次の投稿の本文・カテゴリ情報が混入して投稿された  
**原因**：`post-queue.md` 内の `---` セパレータが欠落しており、`load_queue()` が2件分を1件として読み込んだ  
**修正**：`load_queue()` の分割ロジックを `## 投稿\d+` 見出しで再分割する方式に変更  
**予防策**：キュー追加時に、追加した投稿の直前と直後に `---` があることを目視確認してからpushする

## FP-002：urgent-post.md の誤検知による投稿の完全停止

**発生時期**：2026-07  
**症状**：投稿がゼロになり、`post-log.txt` に「本文なし・スキップ」が延々と繰り返し記録された  
**原因**：`urgent-post.md` のヘッダー行（`# urgent-post.md`等）を `has_urgent=True` と誤判定し、`## 本文` セクションが存在しない空ファイルを処理しようとして無限スキップが発生  
**修正**：`## 本文` セクションが存在し、かつ中身が空でない場合にのみ `has_urgent=True` と判定するよう変更  
**予防策**：`post-log.txt` に「スキップ」が3件連続で記録されていたら即確認する。urgent-post.mdはテンプレートのヘッダーを残したまま保存しない

## FP-003：raw.githubusercontent.com による画像投稿の全件失敗

**発生時期**：2026-07  
**症状**：図解投稿がすべて `error_subcode: 2207052` でAPIエラーになり投稿されなかった  
**原因**：Threads API（Meta）が `raw.githubusercontent.com` ドメインからの画像取得を拒否している  
**修正**：jsDelivr CDN形式（`cdn.jsdelivr.net/gh/...`）またはGitHub Pages形式に変換。post.pyに自動変換処理を追加  
**予防策**：図解投稿の画像URLは必ずjsDelivr形式で書く。`07_ng-rules.md` HARD GATESに明記済み

## FP-004：git push 競合（Actions との同時更新）

**発生時期**：2026-07（複数回）  
**症状**：`git push` が `[rejected] (fetch first)` でエラーになる  
**原因**：GitHub Actions がキュー更新・メトリクス書き込みを行っている最中に push しようとして競合  
**修正**：毎回発生するため標準手順化。以下のコマンドで対処：
```
git stash && git pull --rebase origin main && git stash pop && git push origin main
```
**予防策**：push前に `git status` で未コミット変更を確認する。Actionsの実行タイミング（投稿時刻の前後）は避ける

## FP-005：E投稿の連続配置（アフィリ2本連続）

**発生時期**：2026-07  
**症状**：ぬいぐるみバッグのアフィリ投稿2本をE→Eで連続配置しようとした  
**原因**：投稿数が増えてきた際に前後の間隔チェックを失念  
**修正**：481(A)→482(E)→483(A)→484(B)→485(E) に再配置して前後2本以上の通常投稿を確保  
**予防策**：`07_ng-rules.md` HARD GATESに「E投稿の前後2本以上必須」として明記済み。キュー追加時はEの前後2件を目視確認する

## FP-006：♡外字（U+2661）によるAI感の露出

**発生時期**：2026-07  
**症状**：CTA「♡で教えて」の♡がスマホで外字表示され、読者にAI生成感を与えた  
**原因**：通常ハート絵文字ではなく記号としての♡（U+2661）を使用していた  
**修正**：「いいねで教えて」に変更  
**予防策**：`07_ng-rules.md` HARD GATESに「♡（外字ハート U+2661）の使用禁止」として明記済み

---

## FP-007：「崩れる」などの抽象語による映像の欠如

**発生時期**：2026-07  
**症状**：「子どもが崩れる」という表現が投稿に混入し、読者に場面が浮かばない抽象投稿になった  
**原因**：感情・状態の変化を動詞1語で済ませてしまう習慣  
**修正**：「朝起きた瞬間から不機嫌」「ぐずぐずが止まらない」「『早く帰ろ』が朝からずっと出てくる」のような具体的映像描写に差し替え  
**予防策**：状態変化を表す動詞（「崩れる」「落ちる」「壊れる」「乱れる」）は使用前に「映像として浮かぶか？」を自問する。`07_ng-rules.md` DEFAULTS「感情描写はシンプルに」で対応済み
