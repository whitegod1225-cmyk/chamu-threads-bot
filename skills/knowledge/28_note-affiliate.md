# 28_note-affiliate.md ── 無料note×楽天アフィリエイト記事フォーマット

ちゃむ。の無料noteに楽天アフィリエイトを組み込む専用フォーマット。
通常の育児共感記事（思想・感情ベース）の**箸休め的位置づけ**として、頻度を抑えて出す。

---

## 基本方針

- **思想ベースの投稿が主軸**。グッズ紹介はあくまで補足
- **恒久的に参考になる商品のみ**：ブーム・限定・コラボはNG
- 読者に「保育士が自分で選んで今も使い続けている」という信頼軸で届ける
- スペック列挙ではなく**生活の変化**で語る（05_affiliate.mdの「機能でなくベネフィットで語る」準拠）
- 「これはやめた」を必ず1つ入れる（やめた理由があると信頼度が上がる）

---

## テンプレートタイトル

```
保育士16年のわたしが、育児グッズで本当に使い続けているもの
```

テーマ別バリエーション：
```
保育士16年のわたしが、朝の支度で本当に使い続けているもの
保育士16年のわたしが、イヤイヤ期に本当に手放せなかったもの
保育士16年のわたしが、保育園グッズで本当に買い直したもの
```

## 記事フォーマット（セクション構成）

### 書き出し（敬体・「こんにちは。ちゃむ。です。」から始める）

```
こんにちは。ちゃむ。です。
```

---

### § 1：悩みの代弁（冒頭）

**目的**：読者が「自分のことだ」と感じる入口を作る。

- 読者が毎日直面している「小さな消耗」を1シーンで描写する
- 解決策は出さない。ただ共感するだけ
- 100〜150文字

**書き方の型**：
```
[具体的な時間帯・場面] + [何が起きているか] + [どんな気持ちになるか]
```

**例**：
```
朝7時の玄関。
靴下どこ、上着どこ、水筒どこ。
探しながら子どもをなだめて、保育園の時間に間に合うか毎朝ヒヤヒヤしていました。
保育士として「準備は前日に」とお伝えしていたのに、自分がいちばん前日に何もしていなかった。
```

---

### § 2：体験談（1本）

**目的**：「わたし自身も同じだった」という自己変化告白で信頼を作る。

- ちゃむ。がそのグッズを使い始めた経緯を1本のエピソードとして書く
- 「使い始める前」と「使い始めた後」の生活の変化を描写する
- スペックは書かない。「使ってわかったこと」を書く
- 150〜250文字

**書き方の型**：
```
[使い始めた理由・きっかけ] → [使ってみてわかったこと] → [今の生活の変化]
```

**例**：
```
去年の春、ためしに〇〇を変えてみました。
理由はシンプルで、毎朝「どこ？」と言いながら探す時間をなくしたかったから。
使い始めて最初の1週間、探す回数が明らかに減りました。
「探さなくていい朝」があるだけで、出発前の空気がちょっと変わりました。
```

---

### § 3：商品紹介（複数）

**目的**：「実際に何を使っているか」を具体的に伝える。

- 1商品あたり50〜80文字。スペック列挙ではなく「生活がどう変わったか」
- 最大5商品まで。詰め込まない
- 見出し形式で区切る

**テンプレート（1商品分）**：
```markdown
### [商品カテゴリ・用途]

[使う前の状況] → [これを使うようになってどう変わったか]
どんな人に向いているか1行。

→ 詳しくは記事末尾のリンクから
```

**例**：
```markdown
### 朝の準備をスムーズにする収納グッズ

出発前に「ここを見ればある」という場所が1つできただけで、探す時間がゼロになりました。
朝の準備でいつも同じ場所を探している方に。

→ 詳しくは記事末尾のリンクから
```

---

### § 4：「これはやめた」（必須）

**目的**：やめた理由を正直に書くことで、紹介商品への信頼度が上がる。

- 1〜2商品。「なぜやめたか」の理由を正直に書く
- 批判・否定ではなく「自分には合わなかった理由」として書く
- 読者が「この人は本当のことを言っている」と感じる効果がある
- 100〜150文字

**書き方の型**：
```
[何をやめたか] + [なぜやめたか・自分には合わなかった理由] + [代わりに何をしたか]
```

**例**：
```
以前は〇〇を使っていましたが、わたしには続きませんでした。
理由は[具体的な理由]。
悪い商品ではないのですが、[自分の状況・習慣]に合わなかったんだと思います。
今は[別の方法]の方が自分のリズムに合っています。
```

---

### § 5：おわりに

**目的**：「グッズより考え方が大事」という軸に戻る。

- ちゃむ。の普段の投稿（思想ベース）との一貫性を保つための着地
- 「グッズで全部解決できるわけではないけれど、一つ減らすことで少し楽になる」という温度感
- 80〜120文字

**テンプレート**：
```
グッズが全部を解決してくれるわけではありません。
でも、毎日ちょっと消耗していた1カ所が楽になると、
そこで使えた気力を子どもに向けられる気がしています。

一つでも参考になれば嬉しいです。
ちゃむ。
```

## 商品選定チェックリスト（掲載前確認）

- [ ] 3年以上、または今も継続して使っているか（または現場で長期使用した実績があるか）
- [ ] トレンド・限定・コラボ品ではないか
- [ ] 本文で触れた悩みや場面と直接つながっているか
- [ ] スペックでなく生活の変化で語れるか
- [ ] 「なぜやめたか」を正直に書ける商品が1つあるか
- [ ] 1記事の商品数が5本以内か
- [ ] リンクはコメント欄ではなく末尾の「▼この記事で紹介したグッズ（PR）」セクションに置いているか

## 有料note公開前モニターフロー

有料noteを公開する前に必ずこのフローを実施する。「感想ゼロで公開」は機会損失。

### フロー全体

```
① noteの初稿を書く
↓
② Threadsでモニター5名を募集（無料で読んでもらい感想をもらう）
↓
③ DMでnoteのURLを送付
↓
④ 感想が届いたらnote本文に掲載（スクリーンショット or 引用）
↓
⑤ 感想をThreads投稿でシェア（内容はモザイク。「こんな感想が届きました」型）
↓
⑥ 公開日を投稿でアナウンス
↓
⑦ 公開
```

### モニター募集投稿の型

```
【モニター募集】
○○で悩んでいるママ、5名限定で無料で読んでもらえますか？

保育士16年で見てきた、○○の話をnoteにまとめました
公開前に読んでくれる方を探しています

「読みたい」とコメントかDMください🌱
```

### 注意事項

- モニターはThreadsのフォロワーから選ぶ（ターゲット外の人に頼まない）
- 感想の内容がイマイチでも正直に掲載する（批判でなく「合わなかった点」なら信頼になる）
- 感想をnoteに掲載する前に本人に確認を取る
- モニター期間：2〜3日以内で回収できる量に絞る（長くなると返信率が下がる）
- 公開前に「あと○時間で公開！」の告知投稿を1本入れると到達数が上がる

---

## 公開頻度・位置づけ

- **月1〜2本が上限**。思想・感情系の通常note記事の間に挟む
- 連続公開しない（前後に通常のnote記事を1本以上置く）
- note-index.mdへの追記時、種別を「無料（アフィリ）」と明記する

---

## NGパターン

| NG | 理由 |
|----|------|
| 有料noteへの挿入 | 有料読者の信頼を損なう |
| ブーム商品・限定コラボ | 記事の寿命が短くなる・ちゃむ。の「恒久的な知恵」軸と合わない |
| 本文中へのURL挿入 | 読者が広告として認識した瞬間に読む姿勢が変わる |
| スペック列挙型の紹介 | ちゃむ。の文体・軸と合わない。公式サイトと変わらない |
| 「これを買えば解決！」という断言 | 「05_affiliate.md：うちはこれにした、くらいの温度感」に反する |
| 「これはやめた」を省略 | 信頼構築の核を失う |
